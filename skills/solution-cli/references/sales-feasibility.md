# 销售方案可行性评估与需求匹配度指南 (Sales Feasibility & Matching Guide)

> **定位**：供 AI Agent 在面对 **销售端询问团队技术能力边界（FEASIBILITY）**、**非标定制评估** 以及 **商机匹配度衡量（MATCHING_SCORE）** 时查阅。回答“我们能不能做”、“做这个需要多少周期”、“如何评估需求匹配度”。

---

## 1. 销售需求四级评估阶梯 (The 4-Tier Feasibility Matrix)

当销售或商务询问“某某客户的需求我们能不能接/能不能做”时，严禁盲目回答“可以做”，必须按以下四级阶梯对齐技术成熟度：

| 阶梯等级 | 判定特征与技术依据 | 推荐答复话术与研发周期 |
|---|---|---|
| **Tier 1: 开箱即用 (Turnkey)** | 官方方案库已有现成参考设计（`reference_design`），已有预编译 Docker 镜像与验证硬件（Orin/树莓派/瑞芯微）。 | **“完全支持，开箱即用”**。<br>周期：0 天（到货即部署）。直接提供官方方案落地页、BOM 清单与一键加购链接。 |
| **Tier 2: 模型/协议适配 (Adaptation)** | 硬件算力与物理接口完全满足（如 Orin NX + 工业相机 + RS485），但需要更换目标检测模型（如把人脸换为特定零件缺陷），或需接入私有 Modbus 协议。 | **“技术可行，需轻量适配”**。<br>周期：1~2 周。支持通过开放的 Docker/Compose 与 ONNX/TensorRT 工具链接入，可由客户研发或我方技术支持协助跑通。 |
| **Tier 3: 硬件拓展/研发立项 (Custom Engineering)** | 涉及非标工况（如户外防爆、-40℃ 超宽温、太阳能休眠超低功耗微安级），或需自研特殊算子与驱动（如高频毫米波雷达定制算法）。 | **“需研发评估与项目立项”**。<br>周期：4~8 周以上。需销售组织现场工况评审会，评估硬件选型打样成本与预期出货量。 |
| **Tier 4: 物理超限 (Physically Infeasible)** | 违反物理规律或边缘算力严重倒挂（如要求 ESP32 跑 4K 30FPS 大模型全功能分割、无红外打光在全黑环境要求百米人脸抓拍）。 | **“物理上不可行，需调整方案设计”**。<br>明确解释物理原因（如算力/光学极限），并提供升阶改造建议（如增加外部补光或升级为 Jetson 工控机）。 |

## 2. 需求匹配度四维量化打分法 (Matching Score: 0~100%)

当面对多个商业需求时，利用以下 4 项确定性工程维度进行加权评分，输出结构化匹配卡：

$$Score = \text{算法成熟度}(35\%) + \text{硬件适配性}(30\%) + \text{现场工况条件}(20\%) + \text{交付闭环复杂度}(15\%)$$

```markdown
### 🎯 方案匹配度评估：85% (高匹配 · 推荐推进)

- [x] **算法就绪度 (95%)**：官方已有成熟参考设计，已预置推理管线。
- [x] **硬件适配性 (90%)**：推荐 reComputer J4012 (Orin NX)，算力满足并发路数。
- [!] **现场工况条件 (70%)**：现场需工业防尘，建议选配 IP66 防护机箱与工业级电源。
- [x] **交付周期 (90%)**：纯容器化部署，到货即可完成自动化交付。

💡 **商务建议**：属于成熟方案，交付风险低，建议销售直接输出 BOM 报价并跟进采购。
```

## 3. 双轨业务策略控制 (Business Policy Switching)

根据团队当前交付负荷与销售阶段，Agent 可根据提示词自动切换或由用户指定策略：

### 策略 A：`strict`（严格挑活 · 聚焦标准化规模交付）
- **触发条件**：交付团队高负荷、大促期、或明确要求“只要现成标准方案”。
- **规则**：
  - **匹配度 $\ge 80\%$**：积极推进，提供 BOM 与自动化部署指南；
  - **匹配度 $< 80\%$**：礼貌婉拒非标，守住研发成本底线：
    > *“根据现场工况，目前官方方案库尚无开箱即用的标准套件。为确保您的交付稳定性与工程成本，建议优先考虑标准化场景，或参考 Seeed 开源硬件底座自行评估二次开发。”*

### 策略 B：`flexible`（积极适配 · 扩大商机与生态定制）
- **触发条件**：业务开拓期、新市场线索挖掘、战略大客户定制。
- **规则**：
  - **匹配度 $\ge 50\%$**：积极拆解定制路径：
    > *“目前虽然没有 100% 对应的现成整机套件，但底层硬件平台（如 reComputer Jetson / SenseCAP）具备完全兼容的算力与工业接口，只需 1~2 周进行模型微调或协议适配即可跑通，我们可提供完整的二次开发技术 Wiki 与 GitHub 仓库。”*
