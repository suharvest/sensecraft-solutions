后续发布前必须补齐：

- Orin NX 8GB、Orin Nano 8GB 真机测试。NX 上强制 x264 仅验证软件分支，不能代替 Nano 的 CPU 负载和内存验收。
- 原版 JetPack 6.2 / L4T 36.4.3 全栈测试，尤其是宿主 NVIDIA GStreamer 与容器组合。
- 连续 24 小时摄像头运行、内存/显存/磁盘趋势、长时间断流重连。
- 设备断电后恢复、USB 热插拔与设备节点变化、真实多类别数据的训练与模型上线质量。
- 实际浏览器到 Jetson 的 WebRTC 连通、局域网防火墙与多观看者体验。已验证服务器端 H.264/RTSP，并未完成所有终端网络场景。

首次部署至少预留 18GB，后续数据集与恢复点另计。镜像为预构建 ARM64 包，用户端首次启动不进行源码编译或包安装。候选版本不会自动升级宿主 JetPack 或替换开发项目。
