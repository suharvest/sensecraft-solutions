## 这个方案能帮你做什么

本方案为开发语音 AI、智能交互硬件与会议终端的团队提供开箱即用的声学前端（AFE）调优工作台：
- **纯浏览器运行免装驱动**：利用 WebUSB 与 WebAudio 技术，直接通过 Chromium 浏览器与硬件建立通道，免除在操作系统配置 Python、驱动库与环境变量的繁琐前置步骤；
- **全链路声学效果可视化**：直观呈现环境底噪电平、实时滤波波形对比、扬声器 AEC 回声消除表现，以及声源到达角（DOA）方位追踪；
- **端侧语音转写闭环**：内置端侧轻量 Whisper 引擎，在浏览器本地直接完成录音与转文字验证，保障音频隐私不出本地。

---

## 核心价值与技术规格

| 维度 | 技术规格与特性 |
|---|---|
| **接入协议** | 基于原生 WebUSB 控制通道（VID: `0x2886`）与 WebAudio 采样流，免装私有上位机软件 |
| **支持硬件** | reSpeaker Lite（双麦远场线性阵列，板载 DSP）、reSpeaker XVF3800（四麦环形远场阵列） |
| **波形与电平观测** | 并排对比原始收音通道（Raw Mic）与经过波束成形（Beamforming）、降噪滤波后的处理后音频 |
| **回声抑制测试** | 模拟终端扬声器放音场景，实时测量声学回声消除（AEC）效果，验证打断唤醒（Barge-in）能力 |
| **声源方位追踪** | 支持 360 度声源方位角（DOA）雷达图动态渲染，实时捕获说话人方向 |
| **端侧验证转写** | 基于 WebAssembly 加速的本地 Whisper 模型，全离线执行 ASR 语音识别效果评估 |

---

## 适用场景

- **语音 AI 方案落地前工勘**：在部署大模型语音助手或智能音箱前，测量现场安装位置的背景噪音与回声衰减指标；
- **麦克风阵列硬件选型与验证**：横向对比双麦（reSpeaker Lite）与四麦（reSpeaker XVF3800）在远场、近场及复杂环境下的消噪能力；
- **回声与打断调优**：排查语音交互终端自发自收导致误唤醒的问题，校准扬声器参考信号电平与延迟匹配；
- **教学与声学实验**：高校与实验室用于直观演示波束成形、DOA 定位算法与降噪算法原理。

## 实测效果与使用须知

- **浏览器兼容性**：必须使用支持 WebUSB 标准的 Chromium 内核浏览器（如 Google Chrome 89+、Microsoft Edge 89+）；Safari 与 Firefox 暂不支持硬件 USB 直通控制；
- **安全上下文要求**：网页必须在安全上下文（HTTPS 或 `http://localhost` / `http://127.0.0.1`）下运行，麦克风与 WebUSB 权限才能正常获取；
- **系统授权**：macOS 首次使用时需在「系统设置 → 隐私与安全性 → 麦克风」中授予浏览器麦克风访问权限；Linux 下若普通用户无法打开 USB 设备，请添加 `MODE="0666"` 的 udev 规则；
- **本地转写模型缓存**：首次点击「录音与转录」时会在线拉取约 40MB 的 WebAssembly 模型至浏览器 IndexedDB 缓存，后续使用无需重复下载。
