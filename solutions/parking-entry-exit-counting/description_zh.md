## 这个方案能帮你做什么

用出入口现有摄像头统计车辆进出，剩余车位实时更新。

用出入口现有摄像头统计车辆进出，场内车辆数和剩余车位实时发到你的系统，不埋线圈、不改道闸。面向停车场与集成商，跨平台部署。

- **车辆进出越线统计**：在出入口摄像头画面中设置虚拟计数线，车辆经过时自动识别进出方向并完成计数。
- **场内余位实时发布**：每次车辆进出后自动更新场内总车辆数与剩余车位数，通过 MQTT 毫秒级广播给余位屏或停车管理系统。
- **多车型识别与区分**：支持轿车、货车、公交车、摩托车等多车型目标识别与分类统计。

## 核心价值

- **零工程破路改造**：直接利用出入口现有的 IP 摄像头，无需破土埋设地感线圈，施工成本极低。
- **边缘本地实时分析**：视频解码、车辆检测、跨帧跟踪与越线判定全部在边缘算力盒子上闭环，视频数据不出园区。
- **跨平台算力适配**：支持 reComputer J30 / J40 系列（Jetson Orin Nano / NX）、reComputer RK3576 系列与 RK3588 系列。
- **多出入口轻松汇总**：每个出入口独立部署一套，上层系统通过唯一的停车场与站点 ID 按需汇总全场车辆总数。

## 适用场景

车辆从固定车道进出、需要掌握场内剩余车位的场景：

- **商场、写字楼停车场**：入口余位屏显示剩余车位，随车辆进出自动变化；降到 0 时切换“车位已满”。
- **园区、工厂大门**：统计每天进出车辆数，按车型区分货车和小车，提供车流统计报表。
- **多个出入口汇总**：每个出入口各部署一套，上层系统按停车场编号汇总全场总车位数。

## 使用须知

- **机位要求**：一套设备接一路固定出入口摄像头，覆盖一个车道。摄像头俯视车道，确保车辆通过计数线时不被遮挡。
- **设备选型建议**：reComputer J30 系列与 RK3576 系列支持 30 fps 高速车流；RK3588 主机适合车辆减速或停车抬杆后通过的道闸出入口。
- **网络与接口**：系统通过 MQTT 发送越线事件与车位变更消息，提供 HTTP `/healthz` 健康检查接口。
