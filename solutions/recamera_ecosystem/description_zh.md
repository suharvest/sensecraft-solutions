## 这个方案做什么

插上 AI 摄像头，在浏览器里打开它的控制台，装一个应用：目标检测、文字识别、
人脸分析、困倦监测、天气识别、二维码扫描、健身计数、跌倒检测或零售客流统计。
换应用只需要点一下。所有 AI 都在摄像头上跑，视频不出局域网——需要把结果用到别处时，
摄像头通过 MQTT 发布，Home Assistant 会自动接住。

## 核心价值

| 价值 | 说明 |
|------|------|
| 摄像头自带应用画廊 | 在浏览器里装应用、换应用。下载由你的电脑完成，摄像头本身不需要联网 |
| 一台设备，多种用途 | 同一套硬件，看当前跑的是哪个应用，就能做检测、识字、分析人脸或数客流 |
| 接 Home Assistant 不用写胶水代码 | 摄像头发布 MQTT 自动发现配置，实体自己出现，换应用时也自动跟着变 |
| 默认保护隐私 | AI 在摄像头上跑，视频和检测结果留在局域网内，控制台还能在编码之前就把人脸打上码 |
| 兼容你已有的东西 | RTSP 任何播放器都能看，ONVIF 让 NVR 或监控平台自动发现（reCamera） |

## 两个套餐

| 套餐 | 硬件 | 应用从哪来 | MQTT broker |
|------|------|-----------|-------------|
| **reCamera** | reCamera 2002 | reCamera 控制台的应用画廊，由本方案安装 | 摄像头自带，另外还有部署 Home Assistant 时带的那个 |
| **reCamera Pro** | reCamera Pro | 摄像头自己的应用中心，随固件分发 | 摄像头不自带——broker 来自 Home Assistant 那一步 |

两个套餐是同样的五步：先把设备弄成最新的，挑一个应用，需要的话部署
Home Assistant，让两端连同一个 broker，最后把仪表盘搭起来。

## 画廊里的应用

| 应用 | 做什么 |
|------|--------|
| 通用目标检测 | 人、车等 80 类常见目标 |
| OCR 文字识别 | 从招牌、标签、仪表屏上识别中英文文字 |
| 人脸分析 | 年龄、性别、表情，视频流上可选打码 |
| 困倦检测 | 基于 FaceMesh 的闭眼时长、PERCLOS 和哈欠频率 |
| 天气识别 | 从画面判断晴 / 多云 / 雾 / 雨 / 雪 |
| 二维码识别 | 一次识别画面里的所有二维码，不需要模型，也不需要扫码枪 |
| 健身教练 | 深蹲、俯卧撑、弯举的计数与动作提示 |
| 跌倒检测 | 基于设备本地姿态时序识别快速跌倒，适合固定室内机位 |
| 零售人流分析 | 进出客流统计，外加浏览 / 驻足 / 求助状态 |

reCamera Pro 的应用中心里有其中大部分应用的对应版本，另外还有语音转写。天气识别只有 reCamera 有。

## 使用要求

### 网络

- 摄像头和运行 Home Assistant 的机器（如果用）要在同一个局域网
- 初次配置可以用 USB（地址 `192.168.42.1`）
- 运行本应用的电脑需要能联网，替摄像头下载应用；摄像头自己不需要

### 做 Home Assistant 那两步时

- 运行 Home Assistant 的机器上要有 Docker，8123 和 1883 端口空闲
- 或者你已经有 Home Assistant 和 MQTT broker，那么第 3、4 步就只剩填一个地址

### 隐私

- 所有 AI 检测都在摄像头本地完成
- 视频流和检测数据都留在局域网内
