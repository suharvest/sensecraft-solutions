## このソリューションができること

ネットワークカメラやサーバー、建物の外に出る映像ストリームを一切使わずに、店舗の入店者数、待機列の人数、会議室の実際の在室状況をカウントします。

必要なのは、カメラモジュール 1 枚と USB ケーブル 1 本だけです。Grove Vision AI Module V2 がオンデバイスで人物検出・フレーム間トラッキングを行い、設定したカウントラインの通過数（出入り）や、設定したエリア内にいるリアルタイム人数を計測します。映像は USB 経由で PC のプレビュー画面にのみ送られ、ネットワークやクラウドには一切出ません。

## コアバリュー

| メリット | 詳細 |
|---------|------|
| 完全オンデバイス処理 | 検出・トラッキング・計数はすべて Himax WE2 および Ethos-U55 NPU 上で完結 |
| ネットワーク不要・クラウド不要 | カウント値・検出座標・プレビュー画像は USB 経由のみで伝送され、外部送信ゼロ |
| 自由なライン・エリア設定 | 最大 4 本のカウントライン（双方向独立集計）、最大 4 つのエリア（リアルタイム在室人数） |
| インフラ構築コストゼロ | サーバー不要、アカウント不要、WiFi 設定不要——USB 接続のみで稼働 |
| オープンなデータ出力 | シリアルから SSCMA JSON 形式で出力。自社スクリプトやゲートウェイへ簡単に連携 |

## 適用シナリオ

| シナリオ | 活用方法 |
|---------|---------|
| 店舗入口 | 入口にラインを引いて双方向の入退店者数をカウントし、来店傾向を把握 |
| 待機列・レジ監視 | 待機エリアに枠を引き、滞在人数をリアルタイムに把握してスタッフ配置を最適化 |
| 会議室・執務エリア | 予約システムに頼らず、部屋やブースが実際に利用されているかを検知 |
| 通路・階段の流動計測 | 通行経路に複数のラインを設置し、人流の移動方向と混雑度を可視化 |
| 展示ブース | ブース周辺にエリアを設定して滞在度を測り、入口ラインで訪問者数を集計 |

## 実測データ

| 指標 | 測定結果 |
|------|---------|
| 処理スループット | **約 13 fps** |
| 単フレーム検出遅延 | **48 ms** |
| 人物検出精度 | **92.6% mAP** |

※ Grove Vision AI Module V2（解像度 240x240）での実測値。実際のカウント精度は設置角度、照明、混雑度によって変化するため、現地での検証を推奨します。

## 動作要件と制約

| 項目 | 詳細 |
|------|------|
| ハードウェア | Grove Vision AI Module V2 および USB-C データケーブルのみ |
| カウントライン | 最大 4 本（各ラインで入・出を個別集計） |
| カウントエリア | 最大 4 エリア（エリア内のリアルタイム人数を表示） |
| 照明環境 | 通常の室内照明。被写体背後の強い逆光は精度低下の要因となります |
| 人流密度 | フレーム間の関連付け追跡のため、密集環境での著しい遮蔽は精度に影響します |

## 設置のベストプラクティス

- **斜め見下ろし設置**：検出モデルが学習した標準的な画角を維持できる推奨アングルです。トラッキングのアンカーポイントは必ず **「バウンディングボックス底辺中央（足元）」** に設定してください。ボックス中心をアンカーにすると、人がカメラに近づいた際に検出枠の拡大に伴いアンカーがラインを跨ぎ、誤カウントの原因になります。
- **真上見下ろし設置**：人同士の遮蔽が最小化され、高密度な人流に有効ですが、学習データの関係で真上からの検出率が落ちる場合があります。本番設置前に事前検証を行ってください。
- カウントラインは画面の端に近づけすぎず、ラインの両側で数フレーム安定して追跡できる余白を確保してください。
