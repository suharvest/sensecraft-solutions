## このソリューションでできること

家庭の照明、カーテン、エアコン、Zigbee センサーを Home Assistant に取り込み、声で操作できます。音声認識と音声合成は Jetson 上でローカルに実行されるため、録音がクラウドの音声サービスに送られることはありません。

## 主なメリット

| メリット | 内容 |
|---------|------|
| 声で操作 | 「リビングの照明をつけて」と話すと、Home Assistant が実行して音声で応答します |
| 音声はローカルで処理 | コマンドの理解と応答音声の生成はどちらも reComputer J40 上で実行され、Home Assistant がローカルでコマンドを実行します |
| 高速な応答 | 発話終了から認識テキストまでの中央値 0.12 秒 |
| Apple ホームに対応 | Home Assistant のデバイスが iPhone のホームアプリに表示され、Siri で操作できます |
| ハブなしで Zigbee デバイスを接続 | ZBT-2 を挿せば、Aqara や SONOFF などの Zigbee センサーやスイッチを各メーカーのハブなしで Home Assistant に直接接続できます |

## 利用シーン

| シーン | 使い方 |
|--------|--------|
| リビング、寝室 | スマートフォンを手に取らずに「リビングの照明をつけて」「寝室の照明を消して」と話します |
| 家族で共有 | 家族が iPhone のホームアプリや Siri で同じデバイスを操作します |
| スマートホームインテグレーターの引き渡し | 1 台のホストで複数メーカーのデバイスを接続し、音声サービスはお客様の家庭内で動作します |

## ご利用にあたって

### 主要ハードウェア

| デバイス | 説明 | 必須 |
|---------|------|------|
| ARM64 Linux ホスト (64 ビット OS、8GB RAM) | Home Assistant を実行します | ✓ 必須 |
| reComputer J40 シリーズ (Jetson Orin NX 16GB) | ローカルで音声認識と音声合成を実行します | ✓ 必須 |
| Home Assistant Connect ZBT-2 | Home Assistant ホストの USB ポートに挿して Zigbee デバイスを接続します | ✓ 必須 |
| Home Assistant Voice Preview Edition | 部屋に置く音声端末：コマンドを聞き取り、応答を再生します | ✓ 必須 |
| SONOFF SNZB Zigbee センサー | 室温や湿度などの状態を通知します | 任意 |

### ネットワーク要件

- Home Assistant ホスト、reComputer J40、音声端末を同じローカルネットワークに接続します
- reComputer J40 は初回起動時に音声モデルをダウンロードするためインターネット接続が必要です (ディスクを 30 GB 以上確保してください)。以降、音声認識と音声合成はデバイス上で実行されます
- Apple ホームアプリを使う場合は、iPhone と Home Assistant ホストを同じローカルネットワークに接続します

### 対応言語

- 中国語と英語の音声コマンド

### Xiaomi Home デバイス

- Home Assistant 公式の Xiaomi Home 連携は非商用利用に限りライセンスされているため、このソリューションではインストールしません。個人の家庭で使う場合は Home Assistant に自分でインストールできますが、商用の納品には使用しないでください。

### 実測結果

| 項目 | 結果 |
|--------|--------|
| 中国語と英語の照明オン/オフコマンド | 5 回中 5 回実行、すべて Home Assistant がローカルで処理 |
| 発話終了から認識テキストまで | 中央値 0.12 秒 (0.11〜0.95 秒) |
| 音声合成の最初の音声 | 0.05〜0.12 秒 |

条件：Home Assistant は 8GB RAM の ARM64 Linux ホスト、音声サービスは reComputer J40 (Jetson Orin NX 16GB)。入力は Home Assistant の音声アシスタントに送った合成音声です。
