# 工业 RS485 哑终端变智能对话终端

## 这个方案能帮你做什么

大楼、车间、机房和园区里，往往分布着大量传统工业传感器与仪表——温湿度探头、电表、水表或三色警示灯。它们坚固耐用，但由于缺少现代联网能力、通信协议晦涩，就像一座座孤立沉默的“哑终端”，既不能主动上报状态，也无法直接与现代空间管理系统互动。

这个方案为你提供了一座轻巧的“数字翻译桥梁”：
无需推倒重买昂贵的新设备，只需将 **Seeed Studio XIAO 核心板** 与 **RS485 扩展板** 接入现场现有的 485 线路，就能将传统 RS485 哑终端秒变能够实时“通话”的智能终端。设备状态与监测数据自动呈现在 Home Assistant 大屏上，并支持全屋与空间设备的自动化智能联动。

不仅支持方案自带的标准温湿度传感器，还完全兼容你现有的各种第三方 RS485 设备（电表、三色报警灯、气象仪等），只需通过直观配置即可接入。

## 核心价值

| 好处 | 具体说明 |
|---|---|
| **哑终端秒变智能节点** | 老旧设备不用换，直接拥有接入现代物联网、与大模型平台对话的能力 |
| **支持丰富 485 硬件** | 开箱即用支持工业温湿度探头，更可随心接入工厂现有的电表、报警灯与传感器 |
| **免写代码一键生成** | 告别繁琐的底层通信协议与驱动开发，填入参数自动生成固件 |
| **空间全域设备联动** | 传感器数据秒级推送到 Home Assistant，与空调、照明、风机自动化联控 |
| **局域网自治更安全** | 数据全部在本地局域网内流转，断网照常工作，数据不上公网 |

## 适用场景

| 场景 | 怎么用 |
|---|---|
| **智慧楼宇与空间能源** | 采集老旧配电箱电表、管道温湿度，统一在大屏监控能耗并智能调节暖通空调 |
| **工业车间环境监测** | 采集产线温湿度、粉尘与噪声指标，异常时联动点亮现场三色警报塔灯 |
| **配电房与机房守护** | 7×24 小时自动巡检配电箱温度与湿度，指标越界秒级推送到手机与中控台 |

## 使用须知

### 硬件清单

| 设备 | 说明 | 必需 |
|---|---|---|
| **Seeed Studio XIAO 核心板** | 网关微控制器，支持 XIAO ESP32-C3 / S3 / C6 系列 | ✓ 必选 |
| **Seeed Studio RS485 扩展板** | 专为 XIAO 设计的 RS485 扩展底板，带 120Ω 终端电阻开关与防浪涌保护 | ✓ 必选 |
| **工业 RS485 传感器或设备** | 方案标配工业温湿度计（XY-MD02），也支持用户自备的任意 Modbus RS485 传感器/电表/报警灯 | ✓ 必选 |
| **12V 直流电源适配器** | 为工业级 RS485 传感器提供标准工作电压 | 传感器需要时必选 |
| **USB Type-C 数据线** | 用于将生成的固件写入 XIAO 核心板并供电 | ✓ 必选 |

### 服务器与网络要求

- **编译环境服务器**：只需一台普通的 ARM64 Linux 设备（如瑞芯微 RK3576 / RK3588、树莓派等），4 核以上、4GB/8GB 内存，系统安装好 Docker 即可，无其他任何特殊硬件要求；也支持直接部署在当前电脑的 Docker 中。
- **Wi-Fi 网络**：现场需有 2.4 GHz 频段 Wi-Fi 网络供 XIAO 上报数据。
- **智能中控**：网关节点与运行 Home Assistant 的主机处于同一局域网内。
