## 这个方案能帮你做什么

在手机、平板或电脑的浏览器里遥控 reBot B601-DM 机械臂，也可以让电脑上的 AI 智能体通过 MCP 服务操控它。夹爪上的摄像头显示机械臂看到的画面；你用手带着机械臂示范时，同一个页面可以录制关节数据。

机械臂运行程序（`armd`）和网页控制台跑在装了 B4 CAN 底板的标准版 reCamera 上，遥控不需要另外的主控电脑。

## 核心价值

| 你能得到什么 | 说明 |
|---|---|
| 浏览器遥控 | 在 `http://<摄像头>:8765` 用摇杆、关节按钮和笛卡尔移动控制机械臂；摄像头还会开出自己的 Wi-Fi 热点，手机不经路由器也能连 |
| AI 智能体操控 | [rebot-companion](https://github.com/Seeed-Solution/rebot-companion) 里的 `rebot-mcp` 默认给智能体 14 个工具：读取机械臂状态、拍照、读取检测结果、移动、夹爪、停止 |
| 手眼标定 | 桌上放一个 ArUco 标记做眼在手上标定，导出的 JSON 可直接在 rebot-companion 里加载 |
| 示范录制 | 关节状态和指令按每段示范写成一个 Parquet 文件 |
| 运行程序占用小 | 在 reCamera 上实测：静态二进制 4.1 MB，内存 3.7 MB，7 个电机全部上力矩、50 Hz 控制时占单核 7.0 % |

## 适用场景

| 场景 | 怎么用 |
|---|---|
| 远程搬运 | 手机打开控制台，看着夹爪摄像头的画面，用摇杆移动物体 |
| 智能体实验 | 让 Claude Code 或其他 MCP 客户端读取机械臂状态、拍一张照片、移动到指定位置 |
| 数据采集 | 在控制台开始录制，带着机械臂示范，保存这一段 |
| 视觉标定 | 打印 4x4_50 字典的 ArUco 标记，完成手眼标定，结果用于 rebot-companion 里的看图抓取 |

## 使用须知

### 硬件

| 设备 | 作用 | 必需 |
|---|---|---|
| 装 B4 CAN 底板的 reCamera（SG2002） | 运行 `armd`、控制台和摄像头应用；机械臂接在底板的 CAN 口（`can0`） | ✓ |
| reBot B601-DM 机械臂（达妙电机） | 6 个关节加夹爪；摄像头装在最后一个手腕关节之后 | ✓ |
| 机械臂电源 | B4 底板的 J2 接口输入 12–24 V 直流；摄像头和机械臂电源要共地 | ✓ |
| 电脑（macOS、Windows 或 Linux） | 运行本次部署；安装 AI 智能体服务时也跑在这台电脑上 | ✓ |
| 打印的 ArUco 标记（4x4_50 字典） | 手眼标定 | 标定时需要 |

不支持 reCamera Pro。没有 B4 CAN 底板时，控制台会拒绝启动机械臂应用。

### 网络

- USB 连接时摄像头地址是 `192.168.42.1`；连摄像头的 Wi-Fi 热点（`reCamera-Arm-Teleop`，默认密码 `12345678`）时是 `192.168.16.1`。在实验室以外使用前请修改热点密码。
- 部署时电脑需要联网下载安装包，摄像头不需要联网。

### 测试范围

- 遥控、力矩控制和上面的数据在 reCamera + reBot B601-DM 上实测。
- 手带示范（重力补偿）和点选抓取在仿真和截图测试中测试。使用时让急停按钮在手边。
- rebot-companion 的手眼标定精度用合成数据检查。控制台会给出你自己这次标定的 RMSE。
- 控制台同一时间只运行一个摄像头应用：ArUco 标记或 YOLO 目标检测。
