## 这个方案能帮你做什么

**一台 reCamera 兼具眼睛与大脑，机械臂免外挂工控机，手机连热点即控，AI 智能体直接接管。**

在手机、平板或电脑的浏览器里遥控 reBot B601-DM 机械臂，也可以让电脑上的 AI 智能体通过 MCP 服务操控它。夹爪上的摄像头显示机械臂看到的画面，能识别物体（YOLO）和 ArUco 标记，打印一张标记就能和机械臂完成标定。

机械臂这一侧只有一个应用 rebot-teleop，跑在装了 B4 CAN 底板的标准版 reCamera 上：`armd` 驱动电机并提供网页控制台，`rebot-vision` 负责摄像头。不需要另外的主控电脑，也不需要另装摄像头应用。

## 核心价值

| 你能得到什么 | 说明 |
|---|---|
| 浏览器遥控 | 在 `http://<摄像头>:8765` 用摇杆、关节控制和笛卡尔移动操作机械臂；摄像头还会开出自己的 Wi-Fi 热点，手机不经路由器也能连 |
| AI 智能体操控 | [rebot-companion](https://github.com/Seeed-Solution/rebot-companion) 里的 `rebot-mcp` 跑在你的电脑上，给 Claude Code、Claude Desktop 或其他 MCP 客户端 14 个工具：读取机械臂状态、拍照、识别、移动、夹爪、回零、停放、停止、急停 |
| 按需视觉 | 视频画面、在摄像头 AI 芯片上运行的 YOLO 物体识别、在 CPU 上运行并带 3D 位姿的 ArUco 标记识别；只有控制台或智能体请求时才运行识别 |
| 手眼标定 | 桌上放一个 ArUco 标记做眼在手上标定，导出的 JSON 可直接在 rebot-companion 里加载 |
| 示范录制 | 关节状态和指令按每段示范写成一个 Parquet 文件；打开重力补偿后可以用手带着机械臂示范 |
| 运行程序占用小 | 在 reCamera 上实测：`armd` 静态二进制 4.1 MB，内存 3.7 MB，7 个电机全部上力矩、50 Hz 控制时占单核 7.0 % |

## 适用场景

| 场景 | 怎么用 |
|---|---|
| 远程搬运 | 手机打开控制台，看着夹爪摄像头的画面，用摇杆移动物体 |
| 智能体实验 | 让 Claude 读取机械臂状态、拍一张照片、识别物体并移动到指定位置 |
| 数据采集 | 在控制台开始录制，用手带着机械臂示范，保存这一段 |
| 视觉标定 | 打印 4x4_50 字典的 ArUco 标记，完成手眼标定，结果用于 rebot-companion 里的看图抓取 |

## 使用须知

### 硬件

| 设备 | 作用 | 必需 |
|---|---|---|
| 装 B4 CAN 底板的 reCamera（SG2002） | 运行 rebot-teleop（`armd`、控制台、`rebot-vision`）；机械臂接在底板的 CAN 口（`can0`） | ✓ |
| reBot B601-DM 机械臂（达妙电机） | 6 个关节加夹爪，共 7 个电机；摄像头装在最后一个手腕关节之后 | ✓ |
| 机械臂电源 | B4 底板的 J2 接口输入 12–24 V 直流；摄像头和机械臂电源要共地 | ✓ |
| 电脑（macOS、Windows 或 Linux） | 运行本次部署和 AI 智能体服务 | ✓ |
| 打印的 ArUco 标记（4x4_50 字典，默认边长 5 cm） | 手眼标定 | 标定时需要 |

不支持 reCamera Pro。没有 B4 CAN 底板时，控制台会拒绝启动这个应用。

### 网络

- USB 连接时摄像头地址是 `192.168.42.1`；连摄像头的 Wi-Fi 热点（`reCamera-Arm-Teleop`，默认密码 `12345678`）时是 `192.168.16.1`。控制台和接口没有登录：在实验室以外使用前请修改热点密码。
- 部署时电脑需要联网下载安装包，摄像头不需要联网。

### reCamera 实测数据

摄像头视觉，机械臂不上力矩：

| | 运行在 | 每帧耗时 | 每秒 5 个结果时整颗芯片占用 |
|---|---|---|---|
| 待机（无请求） | — | — | 20–26 % |
| YOLO | AI 芯片（TPU） | 47 ms | 34 % |
| ArUco（640 × 360） | CPU | 37–57 ms（随画面变化） | 53 % |
| YOLO + ArUco | TPU + CPU | — | 55 % |

### 测试范围

- 遥控、力矩控制、重力补偿和上面的数据在 reCamera + reBot B601-DM 上实测。一段 30 秒的手带示范录制得到 1509 帧。
- 点选抓取只在仿真和截图测试中测试过。使用时让急停按钮在手边。
- rebot-companion 的手眼标定精度用合成数据检查。控制台会给出你自己这次标定的 RMSE。
- 录制结果是普通 Parquet 文件，列名沿用 LeRobot 的命名，但不是 LeRobot 数据集；不提供格式转换，也没有测试过用它训练。
- YOLO 使用摄像头上已有的 YOLO11n 模型。没有该模型时，ArUco 标记识别和标定仍可使用。
