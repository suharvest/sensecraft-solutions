## このソリューションでできること

家庭の照明、カーテン、エアコン、Zigbee センサーを Home Assistant に取り込み、声で操作できます。音声認識と音声合成は音声ホスト上でローカルに実行されるため、録音がクラウドの音声サービスに送られることはありません。デバイス操作以外の質問は大規模言語モデル (LLM) が答えます。

## 主なメリット

| メリット | 内容 |
|---------|------|
| 声で操作 | 「リビングの照明をつけて」と話すと、Home Assistant が実行して音声で応答します |
| 音声はローカルで処理 | コマンドの理解と応答音声の生成はどちらも音声ホスト上で実行され、Home Assistant がローカルでコマンドを実行します |
| ほかの質問もできます | 「今日は窓を開けてもいい？」のような質問は LLM が答えます。reComputer J40 と RK1828 カード付きの RK3588 はデバイス上の LLM、そのほかの音声ホストは入力したクラウド LLM サービスを使います |
| 高速な応答 | 発話終了から認識テキストまでの中央値 0.12 秒 |
| Apple ホームに対応 | Home Assistant のデバイスが iPhone のホームアプリに表示され、Siri で操作できます |
| ハブなしで Zigbee デバイスを接続 | ZBT-2 を挿せば、Aqara や SONOFF などの Zigbee センサーやスイッチを各メーカーのハブなしで Home Assistant に直接接続できます |

## 利用シーン

| シーン | 使い方 |
|--------|--------|
| リビング、寝室 | スマートフォンを手に取らずに「リビングの照明をつけて」「寝室の照明を消して」と話します |
| 家族で共有 | 家族が iPhone のホームアプリや Siri で同じデバイスを操作します |
| スマートホームインテグレーターの引き渡し | 1 台のホストで複数メーカーのデバイスを接続し、音声サービスはお客様の家庭内で動作します |

## ご利用にあたって

### 主要ハードウェア

| デバイス | 説明 | 必須 |
|---------|------|------|
| ARM64 Linux ホスト (64 ビット OS、8GB RAM) | Home Assistant を実行します | ✓ 必須 |
| 音声ホスト：reComputer J40 (Orin NX 16GB)、J30 (Orin Nano 8GB)、RK3588、RK3576 (8GB) のいずれか 1 台 | ローカルで音声認識と音声合成を実行します。J40 と RK1828 カード付きの RK3588 (16GB) はローカル LLM も実行します | ✓ 必須 |
| Home Assistant Connect ZBT-2 | Home Assistant ホストの USB ポートに挿して Zigbee デバイスを接続します | ✓ 必須 |
| Home Assistant Voice Preview Edition | 部屋に置く音声端末：コマンドを聞き取り、応答を再生します | ✓ 必須 |
| SONOFF SNZB Zigbee センサー | 室温や湿度などの状態を通知します | 任意 |

### ネットワーク要件

- Home Assistant ホスト、音声ホスト、音声端末を同じローカルネットワークに接続します
- 音声ホストは初回起動時にモデルをダウンロードするためインターネット接続が必要です。以降、音声認識と音声合成はデバイス上で実行されます
- クラウド LLM を使う場合、デバイス操作以外の質問はテキストとして入力した LLM サービスに送られます。デバイス操作のコマンドは認識されれば Home Assistant がローカルで実行します。デバイス名が聞き間違えられた場合はその文が LLM に送られることがありますが、LLM はデバイスを操作したと答えないよう設定されています
- Apple ホームアプリを使う場合は、iPhone と Home Assistant ホストを同じローカルネットワークに接続します

### 対応言語

- 中国語と英語の音声コマンド

### Xiaomi Home デバイス

- Home Assistant 公式の Xiaomi Home 連携は非商用利用に限りライセンスされているため、このソリューションではインストールしません。個人の家庭で使う場合は Home Assistant に自分でインストールできますが、商用の納品には使用しないでください。

### 実測結果

| 項目 | 結果 |
|--------|--------|
| 中国語と英語の照明オン/オフコマンド | 5 回中 5 回実行、すべて Home Assistant がローカルで処理 |
| 発話終了から認識テキストまで | 中央値 0.12 秒 (0.11〜0.95 秒) |
| 音声合成の最初の音声 | 0.05〜0.12 秒 |

条件：Home Assistant は 8GB RAM の ARM64 Linux ホスト、音声サービスは reComputer J40 (Jetson Orin NX 16GB)。入力は Home Assistant の音声アシスタントに送った合成音声です。

| RK3588 音声ホスト | 結果 |
|------|------|
| 「打开客厅灯」(リビングの照明をつけて) | 「打开客厅灯。」と認識され、Home Assistant がローカルで実行し、照明がオン |
| 「今天适合开窗吗」(今日は窓を開けてもいい？) | 「今天适合开窗吗？」と認識され、LLM が回答：RK1828 ローカル LLM 1.45 秒、クラウド LLM 1.59〜1.77 秒 |
| 発話終了から認識テキストまで | 0〜0.13 秒 |

| RK3576 音声ホスト | 結果 |
|------|------|
| 「打开客厅灯」 | 4 回中 2 回は正しく認識され Home Assistant がローカルで実行。残り 2 回はデバイス名が聞き間違えられ (「厅厅灯」「蜻蜓灯」)、LLM に送られました |
| 「今天适合开窗吗」 | 2 回とも正しく認識、クラウド LLM の回答 1.93〜3.31 秒 |
| 発話終了から認識テキストまで | 起動後の最初の文は 9.6 秒、以降 0.23〜0.54 秒 |
| 固定録音での繰り返しテスト | 「打开客厅灯」は 46 回すべて正しく認識 (RK3588 と RK3576 で合成した録音を、音声認識に直接、または Home Assistant の音声アシスタント経由で送信)。「今天适合开窗吗」は 20 回中 10 回で「吗」が繁体字「嗎」になりましたが、意味は同じです |

条件：Home Assistant 2026.9.3 は別の ARM64 Linux ホスト、音声サービスは RK3588 (16GB) または RK3576 (8GB)。ローカル LLM は RK1828 カード上の Qwen3-4B、クラウド LLM は DeepSeek。入力は Home Assistant の音声アシスタントに送った合成音声で、LLM の時間は会話エージェントがテキストを受け取ってから回答するまでです。
