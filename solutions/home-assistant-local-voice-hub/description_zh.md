## 这个方案能帮你做什么

用一句话控制 Home Assistant 里的灯和家电，语音在本地识别。

一句话控制 Home Assistant 里的灯、窗帘和空调，语音识别与合成在本地主机上运行，录音不上云。面向全屋智能集成商与智能家居开发者。

- **本地语音直接控制**：说出“打开客厅灯”、“关闭卧室窗帘”，本地主机秒级识别并执行。
- **全屋设备统一接入**：通过 Home Assistant 统一管理 Zigbee、Wi-Fi 及 HomeKit 设备。
- **语音回复与状态播报**：内置本地 TTS，执行完成后语音播报操作结果。

## 核心价值

- **语音数据全程不出门**：语音识别（ASR）与语音合成（TTS）全部在现场 Jetson 主机上本地运行，保护家庭私密生活。
- **超低时延本地意图解析**：语音结束后本地 ASR 识别文字中位数仅 0.12 秒，操作几乎无等待感。
- **全平台多设备互通**：支持 Apple HomeKit Bridge，家人可使用 iPhone 的“家庭”App 或 Siri 控制同一批设备。
- **模块化解耦架构**：Home Assistant 运行在 ARM64 Linux 主机（如树莓派）上，语音模型运行在专用 reComputer J40 系列上，通过 Wyoming 标准协议解耦互联。

## 适用场景

家里的设备已经或准备接入 Home Assistant、说话的录音不想上传云端的家庭与空间：

- **客厅与卧室**：自然口语控制灯光、窗帘与空调，不用到处找手机或遥控器。
- **全家共用**：家人通过 iPhone 家庭 App、墙壁开关或语音指令操控同一套设备，状态实时同步。
- **智能家居集成商交付**：一台主机统一接入多个品牌的设备，语音服务直接部署在客户家中，合规免除上云顾虑。

## 实测效果

Home Assistant 运行在 8 GB 内存的 ARM64 Linux 主机上，语音服务运行在 reComputer J40 系列（Orin NX 16GB）上：

| 指标 | 典型值 | 设备 |
|---|---|---|
| 中英文开关灯指令 | **5/5 条**本地执行成功 | reComputer J40 系列（J4012） |
| 说完到识别出文字 | **中位数 0.12 秒**（0.11–0.95 秒） | reComputer J40 系列（J4012） |
| 回复语音开始出声 | **0.05–0.12 秒** | reComputer J40 系列（J4012） |

## 使用须知

- **协议与设备**：Zigbee 设备建议搭配 Connect ZBT-2 接入；支持中文与英文语音指令。
- **第三方集成说明**：Xiaomi Home 等外部非官方集成需遵守其各自的开源许可协议，本方案不预装非商用代码。
- **硬件配置**：推荐配备至少 8 GB 内存的 ARM64 Linux 主机运行 Home Assistant，语音服务推荐 reComputer J40 系列（需要至少 30 GB 磁盘空间用于存放模型与运行时）。
