# 小型气象站与环境监测方案

## 方案概述

在智慧农业、光伏电站、工业园区、港口码头与商业园区等现场中，环境气象数据是生产排产、防灾减灾与设施自动化联动的关键依据。标准气象方案采用工业级多要素气象传感器（如 SenseCAP ONE 系列，本方案以 S700 7合1 超声波风速风向、光学雨量、大气压、温湿度及光照传感器为例），搭配 Sensor Hub 4G 工业记录仪直连 SenseCAP 物联网平台（SenseCAP PaaS / Portal），实现户外全天候、高精度环境监测与集中资产管理。

针对现场尚未采购大型气象站硬件、或处于前期系统可行性评估与研发联调阶段的团队，方案同步配套提供低成本自包含的 **桌面入门体验套件**：基于 Wio Terminal 与 Grove 传感器，无需户外气象站硬件即可在工位或实验室完整跑通端侧显示、局域网联动与数据流转，降低前期验证成本。

## 核心优势与架构

| 核心维度 | 工业级标准方案（SenseCAP ONE S700 + 4G） | 桌面入门体验套件（Wio Terminal 选配） |
|---|---|---|
| 适用场景 | 户外野外全天候连续运行（农业、光伏、园区） | 实验室工位、桌面评估与软件原型跑通 |
| 传感形态 | 固态一体化集成（无运动机械部件，IP66 耐候） | 模块化 Grove 外挂（BMP280 + DHT11 + 板载声光） |
| 感知要素 | 7要素集成（风速风向、雨量、气压、温湿度、光照） | 4要素监测（气压、温湿度、光照、环境声级） |
| 通信链路 | 工业级 RS485 Modbus-RTU + 4G 全网通免布线 | 5V USB 独立脱网运行 / 2.4 GHz Wi-Fi 局域网 |
| 离线保障 | Sensor Hub 本地缓存 10 万条，断网后自动补传 | 端侧 2.4 寸 TFT LCD 屏幕脱网独立闭环刷新 |
| 业务系统 | 直连 SenseCAP PaaS / 企业 SCADA / 自动排涝喷淋 | 可选接入 Home Assistant 局域网或云端 API |

## 典型场景

| 场景 | 怎么用 |
|---|---|
| 智慧农业与大棚种植基地 | 实时监测降雨、光照与空气温湿度，根据风雨阈值自动联动排涝泵、卷帘遮阳与水肥灌溉 |
| 工业园区与光伏电站 | 配电区与分布式光伏阵列实时监测风速告警与环境温湿度，保障设施安全并评估发电能效 |
| 实验室与方案商前期评估 | 借助桌面入门套件快速调优环境联动逻辑与大屏看板，验证完毕后平滑替换为工业级传感器 |

## 部署方式与使用须知

方案支持从原型评估到规模化工业部署的平滑过渡：
1. **前期验证阶段**：选用桌面入门体验套件，通过标准 MQTT 或 HTTP 接口对齐业务系统的气象数据字段与预警规则。
2. **正式落地部署**：现场直接安装 SenseCAP ONE S700 7合1 传感器与 Sensor Hub 4G 记录仪，通电即自动上线至 SenseCAP 平台，前端业务与告警逻辑无需二次开发。
