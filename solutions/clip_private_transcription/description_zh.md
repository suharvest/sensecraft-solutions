## 这个方案能帮你做什么

用 reSpeaker Clip 录下的会谈、问诊、门店对话，通常要传到手机 App 和云端才能转成文字。这个方案让录音直接同步到你自己的 reComputer Jetson 主机上转写，录音不出现场，转写结果在本地网页里查看，也可以接进你自己的系统。

## 核心价值

| 好处 | 具体说明 |
|------|---------|
| 录音留在现场 | 录音经蓝牙从 Clip 同步到主机，转写在主机上完成，不需要上传云端 |
| 分清谁说了什么 | 每段文字带时间戳和说话人标签，中文、英文、日文都能识别 |
| 处理快 | 在 Jetson Orin NX 上，34 秒的两人日语录音 2.2 秒转写完成，并分出 2 位说话人 |
| 可接入自有系统 | 转写完成时通过 MQTT 发出通知，你的程序再通过 HTTP 接口取回全文 |

## 适用场景

| 场景 | 怎么用 |
|------|--------|
| 门店 / 柜台服务 | 店员佩戴 Clip，回到主机附近后录音自动同步，店长在结果页查看当天对话 |
| 访谈与会议记录 | 采访结束把 Clip 放在主机旁，同步完成后得到分好说话人的文字稿 |
| 对隐私要求高的场合 | 诊室、法务、内部会议等录音不能出场地的地方 |
| 接入业务系统 | 转写完成后由你的系统自动拉取文本，写入工单或客户档案 |

## 使用须知

### 核心硬件设备

| 设备 | 说明 | 必需 |
|------|------|------|
| reSpeaker Clip | 佩戴式录音设备 | ✓ 必选 |
| reComputer J40（Jetson Orin NX，JetPack 6.2） | 同步录音、转写并提供结果页 | ✓ 必选 |
| Jetson 无线网卡模块（Wi-Fi + 蓝牙） | 主机通过蓝牙连接 Clip；选购 reComputer J40 时一并选择 | ✓ 必选 |

- 目前只支持 Jetson Orin NX 模组搭配 JetPack 6.2，其他 Jetson 型号和 JetPack 版本不能部署。
- 主机需要至少 15 GB 可用磁盘。
- 一个 Clip 只能绑定这台主机，不能同时绑定手机 App。

### 网络要求

- 首次部署需要联网，下载语音识别模型（约 1.8 GB）和运行环境；之后转写不需要联网。
- Clip 默认经蓝牙同步，Clip 需要在主机的蓝牙范围内。
- 可选：开启 Wi-Fi 加速同步后，主机会连上 Clip 自己开的热点下载录音。主机用网线上网时直接用自带 Wi-Fi；主机靠 Wi-Fi 上网时，需要再加一个 USB 无线网卡。
- 可选：AI 摘要需要一个兼容 OpenAI 接口格式的 AI 对话服务。使用云端服务时，转写文字会发给该服务（录音本身不发送）；使用你内网里的服务时，全部数据留在现场。
