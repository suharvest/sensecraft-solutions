## 这个方案能帮你做什么

用停车场现有摄像头逐个车位判断有没有车，余位实时可查。

用停车场现有摄像头逐个车位判断占用或空闲，状态经 MQTT 发到余位屏和停车系统，不装车位检测器，视频不出场地。面向停车场运营与系统集成商，跨平台部署。

- **逐车位视觉检测**：在摄像头画面中为每个车位标定多边形区域，算法自动评估车辆覆盖度，毫秒级判定“占用”或“空闲”。
- **余位状态实时广播**：每个车位的实时状态与分区域剩余车位数通过 MQTT 广播，支持直接驱动余位显示屏或对接车位引导系统。
- **多路摄像头统一汇聚**：单台边缘主机支持接入多路 RTSP 摄像头，集中覆盖数十至数百个车位。

## 核心价值

- **零专用传感器安装**：直接复用场内已有的监控摄像头，无需在每个车位破顶安装超声波探头或在地面打孔埋设地磁。
- **全流程本地离线分析**：视频取流、解码与车位占用判定全部在边缘盒子上闭环完成，原始视频不出场地。
- **开箱即用可视化标注**：内置 Web 端车位画框工具，直接在监控画面上拖拽矩形并微调角点贴合车位线，保存即生效。
- **多主流算力平台支持**：支持 reComputer J30 / J40 系列（Jetson Orin Nano / NX）、reComputer RK3588 系列与 RK3576 系列。

## 适用场景

摄像头能从高处俯视车位、需要实时掌握车位空闲情况的停车场：

- **地下车库余位屏**：每层部署几路摄像头，汇总各层空闲车位数，实时显示在入口和各层余位屏上。
- **商场与写字楼区域引导**：按区域（如 A 区、B 区、VIP 区）统计空位，引导车流去往空闲区域。
- **专用车位管理**：给充电桩车位、访客车位或无障碍车位单独划定多边形，被占用时实时通知管理人员。

## 实测效果

每路摄像头每秒分析 1 帧：

| 指标 | 典型值 | 设备 |
|---|---|---|
| 单主机同时处理路数 | **6 路**（连续 620 秒无丢帧） | reComputer J30 系列（J3011） |
| 摄像头断流后车位标为“未知” | **约 10 秒** | reComputer RK3576 系列 |

## 使用须知

- **机位与构图**：摄像头需从高处斜向下俯视车位，保证各车位在画面中不被相邻车辆完全遮挡；一个标注框仅对应一个独立车位。
- **多路接入建议**：接入多路流时逐路添加，在车位管理界面确认每路都在稳定输出更新状态。
- **接口与协议**：系统通过 MQTT 发送车位占用状态消息，并提供 HTTP `/healthz` 健康检查接口。
