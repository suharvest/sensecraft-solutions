## このソリューションでできること

駐車場のどの区画が埋まっているかを知るには、通常は区画ごとに地磁気センサーや超音波センサーを設置し、それぞれに配線・給電・保守が必要です。このソリューションは現場の既存 IP カメラを使います。カメラに映る区画はすべて監視対象にできます。Web ページで区画ごとに枠を描くと、エッジボックスが各枠に車があるかを継続して判定し、各区画の在車 / 空車の状態をお客様のシステムへ送ります。誘導表示、案内、課金に利用できます。

## 主なメリット

| メリット | 内容 |
|------|------|
| 区画ごとのセンサー不要 | カメラ 1 台で映っている区画をすべてカバー。区画ごとの設置や配線は不要です |
| 数秒で状態変化を通知 | 車が停まってから約 3 秒で在車、出てから約 5 秒で空車に切り替わります |
| 区画は自分で描く | Web ページのライブ映像上で区画を描いて名前を付けます。保存するとすぐ反映され、再起動後も保持されます |
| 映像は現場に保存 | 映像はエッジボックスで解析し、外に出るのは区画の状態だけで、映像は出ません |
| カメラ停止を検知 | カメラのストリームが途切れて約 10 秒後、その区画は古い状態を出し続けず `unknown` になります |

## 利用シーン

| シーン | 使い方 |
|------|------|
| 地下駐車場の誘導表示 | 各フロアにカメラを数台設置。フロアごとに空き区画を合計し、入口と各フロアに表示します |
| 商業施設・オフィスの駐車場 | ゾーンごとに空き区画を数え、まだ空いているゾーンへドライバーを案内します |
| 専用区画 | EV 充電区画や来客区画を別の枠で描き、埋まったときにスタッフへ通知します |
| 区画の稼働率 | 各区画の在車時間を記録し、ピーク時間帯や使われていない区画を把握します |

## デプロイ後に得られるもの

- **区画エディター**：ブラウザで開き、カメラを選んで区画の周りをクリックして描き、番号 (例：B1-023) を入力して保存します。
- **区画状態メッセージ**：カメラごとに 1 つの MQTT トピック `<site-id>/parking/<camera-id>/slots`。いずれかの区画が変化するたびに、そのカメラの全区画の状態 (`occupied` / `free` / `unknown`) と在車・空車・不明の台数を含むメッセージを送ります。誘導表示、駐車場システム、Home Assistant はこのトピックを購読します。

## ご利用にあたって

### 主要ハードウェア

| デバイス | 役割 | 必須 |
|------|------|------|
| reComputer J30 / J40 (Jetson Orin Nano / Orin NX、JetPack 6.2) | 区画検出を実行。Jetson Orin Nano または Orin NX モジュール、JetPack 6.2 が必要です | いずれか 1 つ |
| reComputer RK3588 | ボード内蔵の AI アクセラレーターで区画検出を実行 | いずれか 1 つ |
| reComputer RK3576 | ボード内蔵の AI アクセラレーターで区画検出を実行 | いずれか 1 つ |
| IP カメラ | 既存のカメラ。H.264 の RTSP ストリームを出力できること | ✓ 必須 |
| MQTT サーバー | 区画の状態を受け取ります。例：既存の Mosquitto | ✓ 必須 |

実測性能 (各カメラを 1 フレーム/秒で解析)：

| エッジボックス | 1 フレームあたりの時間 | 複数カメラ |
|------|------|------|
| reComputer J30 (Jetson Orin Nano) | 約 6.5 ms | 6 台同時、各 1 フレーム/秒でフレーム落ちなし |
| reComputer RK3588 | 約 37 ms | カメラを 1 台ずつ追加し、それぞれ更新が続くことを確認してください |
| reComputer RK3576 | — | カメラ 1 台で測定。カメラを 1 台ずつ追加し、それぞれ更新が続くことを確認してください |

### ネットワーク要件

- エッジボックス、カメラ、MQTT サーバーを同じ LAN に接続し、エッジボックスから各カメラの RTSP アドレス (通常はポート 554) に到達できること。
- エッジボックスはデプロイ時にプログラムと検出モデルをダウンロードするためインターネット接続が必要です。以降はオフラインで動作します。
- お使いのパソコンからエッジボックスのポート 8080 (区画エディター) に到達できること。

### カメラ要件

- 各区画がはっきり見え、隣の車で完全に隠れないよう、カメラは高い位置から見下ろす角度で設置してください。
- 1 区画に 1 枠。駐車した車が枠のおよそ 3 分の 1 を覆うと在車と判定します。複数区画にまたがる大きな枠や、遠くの小さく映る車を囲んだ枠は在車になりません。
- カメラのサブストリーム (H.264) で十分です。
