# 投放点垃圾分类

拍一张物品照片，给出材质和中国生活垃圾四分类，通过 MQTT 发出。

## 这个方案做什么

按钮、HTTP 调用或画面移动触发拍照，设备把物品分到 8 个物料类别，再得到中国四分类（可回收物 / 厨余垃圾 / 有害垃圾 / 其他垃圾）。结果通过 MQTT 发出，也可交给翻盖、继电器或指示灯。图片不出设备。

## 你会得到什么

- **一次触发一个答案**：按钮、HTTP 或移动侦测触发，800 ms 去抖。
- **两层结果**：物料类别 + 四分类，附 top3 置信度。
- **按当地口径改表**：四分类由查表得到，规则变化不用重训。
- **可选开放词汇模式**：不重训加类别，中英文都能回答，能标出不在词表里的物品。
- **执行机构回调**：四分类结果可接翻盖、继电器或指示灯。
- **本地调试页**：实时画面、推理耗时、最近结果。

## 适合接到哪里

- 家用与社区投放点：投放时拍下单件物品，提示该进哪个桶。
- 分拣工位：操作员逐件展示物品，结果经 MQTT 留记录。
- 带电动翻盖或分道指示灯的垃圾桶。

不适用：传送带分拣、路面散落垃圾检测。

## 分类器选型：基线 vs 开放词汇

| | 基线（EfficientNet-Lite0） | 开放词汇（SigLIP 2） |
|---|---|---|
| 物料 top-1 | **0.8877** | **0.8501** |
| 不重训加类别 | 否 | 是 |
| 词表外拒识 AUROC | — | **0.7538** |
| 中英文四分类一致率 | — | **0.9143** |
| 速度 | 基准 | CPU 单图约 **67 ms**，慢 4–5 倍 |

部署时用 `model.track` 选择。

## 输出接口

| 接口 | 内容 |
|---|---|
| MQTT `waste/<stream-id>/results` | 每次分类一条：物料类别、四分类、top3、图片引用 |
| HTTP `/trigger` | 触发一次拍照分类 |
| HTTP `/preview.mjpg`、`/healthz`、`/events` | 实时画面、计数与耗时、最近结果 |
| GPIO 回调 | 四分类结果回调，接线需自行集成 |

## 使用须知

- 一图一件：一帧有两件物品只返回一个答案。
- 模型不会输出 textile 和有害垃圾。
- 拿不准的物品偏向 organic（训练数据中约占 48%）。
- 四分类映射表与各城市口径可能不同，上线前按当地规则核对，并用现场图像复测。
- 物品在画面中过小会降低准确率。
- 随包 MQTT broker 允许匿名连接，正式部署换带凭据的 broker。
- 执行机构回调默认关闭（`actuator.enabled: false`），需自行提供绑定代码。
