## 套餐: 部署 E1003 {#usb_candidate}

只需同一表单、一次提交：**填写配置 → 自动检查并按需安装 → 保存与复位验证**，之后在 Home Assistant 单独验证控灯。
以下说明面向统一流程 App（contract 12）。正式候选仍禁用，等待公开契约和固件资源同步；当前三个人工审阅步骤只说明流程，不执行写入。

## 步骤 1: 连接设备并填写配置 {#flash_panel type=manual required=true config=devices/review_flash.yaml}

使用唯一的“部署 E1003”入口。用户无需选择烧录或仅配置；App 会自动判断。

### 前置条件

准备兼容的测试 App、USB 数据线和可调光灯的 Home Assistant 实体 ID。电脑、面板和 Home Assistant 需在同一可达局域网；首次联网准备 Wi-Fi 名称和密码。

### 接线

1. 用 USB 数据线连接 E1003 底板的 USB-UART 口与电脑，关闭占用该端口的工具。
2. 在 App 内置表单选择设备端口，填写以下配置。后续检查、安装和保存均在这一表单继续。

| 设置 | 怎么填 |
| --- | --- |
| USB 端口 | 选择已连接的 E1003 |
| 按钮控制的灯 | 粘贴灯的实体 ID，如 `light.bedroom`；开关与四档亮度共用这盏灯 |
| Wi-Fi 名称 | 首次联网时填写；同一 App 已有设备记录且设备已联网时可留空 |
| Wi-Fi 密码 | 填写所选网络的密码；输入默认遮蔽 |

### 故障排查

| 问题 | 处理 |
| --- | --- |
| 找不到端口 | 检查数据线，并关闭占用端口的工具 |
| 看不到统一部署表单 | 确认测试 App 包含 contract 12 的统一流程；正式候选尚未开放执行 |

## 步骤 2: 部署并保存配置 {#configure_panel type=manual required=true config=devices/review_setup.yaml}

在上述同一表单点击 **部署并保存配置**，保持 USB 连接。App 自动执行：

1. 核对固件项目标识、版本、硬件类型及设备名称；全部匹配则跳过烧录。
2. 需要安装时，先核对预编译镜像大小和 SHA-256，再写入、校验并复查固件身份。不全片擦除，保留配置分区。
3. 生成或复用设备独立密钥，写入配置，等待至少 65 秒，再复位并加密读回。全部通过后才显示保存成功，随后可点击复制密钥。

串口不可用或明确识别为其他硬件时停止处理。检查或安装失败时不会继续写配置；保持供电，按错误提示处理后重试。

### 故障排查

| 问题 | 处理 |
| --- | --- |
| 镜像缺失或校验失败 | 使用资源完整的测试包；不要自行换用同版本的其他镜像 |
| 不确定是否保存 | 等待复位和加密读回通过，不要在安装、保存或复位时拔线 |
| 已配置设备缺少密钥记录 | 回到保存过该设备记录的 App；不要通过擦除配置尝试恢复 |

## 步骤 3: 在 Home Assistant 验证控灯 {#verify_ha type=manual required=true verify=true config=devices/review_ha.yaml}

这一步需要真实 Home Assistant 和灯具，仍待实机验收。

1. 确认发现的 ESPHome 设备；未发现时，用设备 IP 和端口 `6053` 手动添加。
2. 在 App 配置面板点击 **复制加密密钥，用于添加 Home Assistant**，在 Home Assistant 粘贴。
3. 勾选 **允许设备执行 Home Assistant 动作**。
4. 测试开关和 25%、50%、75%、100% 四档亮度，再关闭 App 复测；记录灯具是否实际响应。

### 故障排查

| 问题 | 处理 |
| --- | --- |
| 无法连接 | 检查局域网、设备 IP 和连接密钥 |
| 灯没有响应 | 检查“按钮控制的灯”、调光支持和动作权限 |
| 屏幕数值未跟随灯变化 | 动态状态与亮度同步仍需 HA Blueprint 或适配，不属于已验证能力 |
