## 套餐: 安装与设置 {#usb_candidate}

本地联调按 **安装程序 → 联网并设置按钮 → 在 Home Assistant 测试** 进行。
本地 App 的配置入口会打开可编辑的设置页，无需手动命令；正式候选尚未启用。

## 步骤 1: 安装面板程序 {#flash_panel type=manual required=true config=devices/review_flash.yaml}

已安装面板程序时，直接进入步骤 2，无需再次烧录。首次安装使用预编译程序，无需编译或修改配置文件。
本地测试使用已导入的独立测试方案；正式候选尚未附可直接部署的固件资源。

### 前置条件

准备一盏已接入 Home Assistant、支持调光的灯，并复制它的实体 ID。
配置电脑、面板和 Home Assistant 需在同一可达局域网。

### 接线

1. 用 USB 数据线连接 E1003 底板的 USB-UART 口与电脑，关闭占用该端口的工具。
2. 在 App 选择连接的面板端口，再执行安装。保持默认的“不全片擦除”，全程稳定供电。

### 故障排查

| 问题 | 处理 |
| --- | --- |
| 找不到端口 | 检查数据线，并关闭占用端口的工具 |
| 没有安装入口 | 确认打开的是已导入的本地测试方案 |

## 步骤 2: 联网并设置按钮 {#configure_panel type=manual required=true config=devices/review_setup.yaml}

从 App 的配置入口打开本地设置页，选择配置预设后填写表单。提交后，适配器会写入设备。

| 设置 | 怎么填 |
| --- | --- |
| USB 端口 | 选择已连接的 E1003 |
| 按钮控制的灯 | 粘贴灯的实体 ID，如 `light.bedroom`；开关和四档亮度共用这盏灯 |
| Wi-Fi 名称（可选） | 已联网时留空；首次联网或更换网络时填写 |
| Wi-Fi 密码（可选） | 填写所选网络的密码 |
| 复制设备连接密钥（可选） | 配置成功后复制到本机，供 Home Assistant 使用 |

提交后保持 USB 连接。适配器会等待至少 65 秒、复位并加密读回，全部通过后才报告成功。连接密钥由私有记录复用或首次生成，不需要填写。

### 故障排查

| 问题 | 处理 |
| --- | --- |
| 不知道灯的实体 ID | 在 Home Assistant 实体列表中找到对应灯，复制以 `light.` 开头的 ID |
| 不确定是否保存 | 等待配置步骤报告成功，不要在保存和复位过程中拔线 |

## 步骤 3: 在 Home Assistant 启用控制 {#verify_ha type=manual required=true verify=true config=devices/review_ha.yaml}

1. 确认发现的 ESPHome 设备；未发现时，用设备 IP 和端口 `6053` 手动添加。
2. 在配置表单勾选复制 **设备连接密钥**，成功后在 Home Assistant 粘贴。
3. 勾选 **允许设备执行 Home Assistant 动作**。
4. 测试面板开关和四档亮度，再关闭 App 复测。

### 故障排查

| 问题 | 处理 |
| --- | --- |
| 无法连接 | 检查局域网、设备 IP 和连接密钥 |
| 灯没有响应 | 检查“按钮控制的灯”填写是否正确、灯是否支持调光，以及动作权限 |
| 屏幕数值未跟随灯变化 | 状态与亮度同步仍需 HA Blueprint 或适配；按钮绑定不会自动完成显示同步 |

### 部署完成

分别确认：程序已安装、复位后设置保留、真实灯能响应按钮。
当前表单的新网络配网、真实 HA 控灯与屏幕同步仍待验收，安装或配置成功不等于整套方案完成。
