## 套餐: USB 配置 {#usb_candidate}

当前为候选方案，暂不能在 App 中完成部署。以下内容用于说明配置流程；在功能入口正式开放前，请勿当成已可执行的步骤。

## 步骤 1: 连接 E1003 {#flash_panel type=manual required=true config=devices/review_flash.yaml}

USB 固件写入入口暂未开放。连接设备前，请准备好 USB 数据线，并关闭电脑上可能占用串口的其它工具。

### 前置条件

准备一台 reTerminal E1003、一套运行中的 Home Assistant 以及一盏可调光灯。
配置电脑、E1003 与 Home Assistant 必须处于同一可互通的局域网内。

### 接线

1. 用 USB 数据线将 E1003 底板的 USB-UART 口连接至电脑。
2. 写入固件及保存配置期间，确保供电稳定，不要拔出线缆。

### 故障排查

| 问题 | 解决办法 |
| --- | --- |
| 找不到设备端口 | 检查 USB 线是否支持数据传输，并关闭占用该串口的其它程序 |
| 没有固件写入入口 | 该功能尚未开放，当前版本暂不能直接部署 |

## 步骤 2: 设置 Wi-Fi 和灯光目标 {#configure_panel type=manual required=true config=devices/review_setup.yaml}

此步骤的 App 配置入口尚未开放。功能接入后，用户将在 App 中输入 Wi-Fi 名称与密码，并填入目标灯的实体 ID（例如 `light.bedroom`）。每台面板将使用独立的加密密钥。

更改灯光目标后，请保持通电至少 65 秒，让设置充分写入存储，之后再断电或重启设备。

### 故障排查

| 问题 | 解决办法 |
| --- | --- |
| 不清楚灯光实体名称 | 打开 Home Assistant 的实体列表，找到对应的灯，复制以 `light.` 开头的实体 ID |
| 不确定设置是否已保存 | 保持通电 65 秒后，重启设备检查配置是否依然生效；刚设置完立即读回并不代表已写入闪存 |

## 步骤 3: 在 Home Assistant 确认设备 {#verify_ha type=manual required=true verify=true config=devices/review_ha.yaml}

完成设备配置后，再进行以下检查。

1. 在 Home Assistant 中确认自动发现的 ESPHome 设备。若未自动发现，可手动添加 ESPHome 集成，填入设备 IP 和端口 `6053`。
2. 输入该面板专属的加密密钥（App 内查看或复制密钥的功能仍在接入中）。
3. 在 ESPHome 集成选项中勾选 **允许设备执行 Home Assistant 动作**。
4. 在面板上测试开关和调光操作，随后退出 App，再次测试面板是否仍可正常控制。

### 故障排查

| 问题 | 解决办法 |
| --- | --- |
| Home Assistant 连不上面板 | 检查局域网连接是否通畅，确认 IP 地址、端口与加密密钥无误 |
| 触摸面板后灯光无反应 | 确认灯光实体填写正确、灯具支持调光，并已开启「允许设备执行 Home Assistant 动作」权限 |
| 屏幕显示没有同步灯光状态 | 任意灯光目标的状态与亮度同步功能尚未完成，需要后续 HA Blueprint 或适配支持 |

### 部署完成

方案正式发布时的验收标准：设备重启后配置依然保留；关闭 App 后面板依然能控制灯光；屏幕状态与亮度能与目标灯保持同步。
当前版本暂无法完成整套部署，勾选上述清单并不代表设备已配置成功。
