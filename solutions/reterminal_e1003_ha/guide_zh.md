## 套餐: 配置 E1003 {#usb_candidate}

通过 USB 连接 E1003 面板并指定要控制的灯。App 会自动检查固件并在需要时安装，然后保存配置。

> 本方案当前处于技术审阅状态，保持禁用。该人工步骤用于核对配置流程，不会对硬件写入；完整执行需等待 App 契约同步与固件公网链接。

## 步骤 1: 配置 E1003 {#review_setup type=manual required=true verify=true config=devices/review_setup.yaml}

在兼容的测试 App 中填写配置并点击 **保存配置**，等待界面显示 **配置已保存并验证**。

### 前置条件

- 一台 reTerminal E1003 面板与一根 USB 数据线。
- 一盏已接入 Home Assistant 的调光灯，记录其实体 ID（例如 `light.bedroom`）。
- 电脑、E1003 面板与 Home Assistant 处于同一局域网。

### 接线

1. 使用 USB 数据线连接 E1003 底板的 USB-UART 口与电脑。
2. 在 App 的串口列表中选择该设备端口（若列表为空，点击同行的“刷新”）。

### 配置

1. **填写要控制的灯**：在“按钮控制的灯”输入框中填入 Home Assistant 的调光灯实体 ID（例如 `light.bedroom`）。此处需手动填写，App 不会自动搜索灯具。
2. **Wi-Fi 设置（可选）**：设备初次联网或更换网络时，填写 2.4 GHz Wi-Fi 的名称与密码；如果设备此前已连过该 Wi-Fi，名称和密码留空即可直接复用（留空不代表 App 已自动探测到网络）。
3. **保存与验证**：点击 **保存配置**。App 会先检查设备固件版本，不匹配时自动下载并烧录预编译固件，然后写入灯光绑定设置。
4. **等待完成**：配置写入后需重启并读回验证，请保持通电至少 65 秒。只有当界面显示 **配置已保存并验证** 时才算完成（倒计时归零或显示“正在重启”期间请勿断电）。

### 部署完成

只有在 App 明确提示 **配置已保存并验证** 后，再执行后续步骤：

1. 记下成功界面显示的 **设备地址**。
2. 打开 Home Assistant，在“配置 → 设备与服务 → 集成”中添加 ESPHome 设备，填入该设备地址（无需填写 API 密钥）。
3. 在该设备的选项设置中，勾选“允许设备执行 Home Assistant 动作”。
4. 按压面板上的开关键以及 25% / 50% / 75% / 100% 亮度区域测试调光，随后可关闭 App 复测。
> **注意**：面板目前仅定义了这五个触控区域，其他图标无点击响应；配置保存成功不代表实体控灯或屏幕状态双向同步已全部验收。

### 故障排查

| 现象 | 处理方式 |
| --- | --- |
| 找不到设备串口 | 点击刷新按钮；检查 USB 数据线是否支持数据传输；退出可能占用串口的其它程序 |
| 配置或写入失败 | 根据界面上的具体错误信息处理后重试，切勿全片擦除 NVS |
| 界面提示正在保存或重启 | 保持设备供电，耐心等待读回并显示最终验证状态 |
| 按键无反应或灯具不响应 | 确认目标灯实体 ID 正确且支持调光；检查 Home Assistant 中是否已开启“允许设备执行动作”权限 |
