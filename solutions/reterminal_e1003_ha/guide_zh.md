## 套餐: USB 接入审阅 {#usb_candidate}

## 步骤 1: 审阅 USB 固件 {#flash_panel type=manual required=true config=devices/review_flash.yaml}

**源码候选在此阻塞：** 当前没有公开固件资源。维护者可按
[资源说明](assets/firmware/README.md)准备锁定版本的本地固件。
只有单独生成的本地审阅副本会把本步替换为 `esp32_usb`，方案仍保持禁用。
源码包中的本步不会烧录设备。

### 前置条件

仅限 E1003 和现有固定布局。实机测试前关闭串口监视器，并协调设备独占使用。
选择真实端口；`1a86:7522` 仅用于提示，不能代替设备身份检查。
已审阅配置以 115200 波特率把 factory image 写到 0x0，关闭全片擦除。
正常 USB 更新时不要开启擦除。

### 接线

1. 使用数据线连接 E1003 底板 USB-UART 端口与电脑。
2. 烧录和后续保存配置期间保持稳定 USB 供电。

### 故障排查

| 问题 | 处理方法 |
| --- | --- |
| 候选方案没有烧录控件 | 维护者须先准备哈希完全匹配的本地 factory image；当前无下载 URL |
| 串口被占用 | 与占用者协调并关闭串口监视器，不争抢其他会话的端口 |
| 重开串口后设备未启动 | 适配器须显式执行 WCH 复位并等待十秒启动 |
| 更新时提供全片擦除选项 | 保持关闭；若 engine 无法保留该选择，应停止 |

## 步骤 2: 审阅 App 配置依赖 {#configure_panel type=manual required=true config=devices/review_setup.yaml}

**阻塞：** 当前内容无法向设备写入 Wi-Fi、API key 或灯光目标。
本步仅作人工审阅标记，不执行配置。不能把人工步骤完成当成设备配置成功，
也不应让最终用户运行维护者脚本绕过。

后续 App 适配器须收集 Wi-Fi 名称和密码，为每台设备生成并私密保存独立 API key，
再通过加密的原生 API 写入并读回用户粘贴的 `light.xxx` 目标。
适配器还须核对身份、安全重试 key 激活，并在最后一次目标写入后提供至少
65 秒保存倒计时，之后才允许断电检查。写入能力接入前，本候选不提供这些输入表单。

### 故障排查

| 问题 | 处理方法 |
| --- | --- |
| Wi-Fi 失败 | 适配器须报告 Improv 错误，允许更正，并保留 key 恢复记录 |
| 初始 key 设置超时 | 复位后在十分钟设置窗口内重试，复用私有恢复记录 |
| 已经安装 key | 使用已保存的 key 重连；重试时不得生成新 key 覆盖 |
| 目标读回一致 | 仅证明当前内存值；须等待保存，再复位验证 |

## 步骤 3: 检查 Home Assistant 验收项 {#verify_ha type=manual required=true verify=true config=devices/review_ha.yaml}

**适配器实现后的验收清单。** 本步是人工验证，不能作为自动验收证据。
当前禁用候选无法完成前面的设备配置。

1. 在 HA 确认发现的 ESPHome 设备。无法自动发现时，用已验证的设备 IP 和
   TCP 6053 添加 ESPHome。Improv 响应 URL 仅携带地址信息，不是设备网页。
2. 在 App 通过明确的私密显示或复制操作取得该设备加密 key，填入 HA 集成。
   不要把 key 粘贴进日志或报告。
3. 在 ESPHome 集成选项启用 **允许设备执行 Home Assistant 动作**。
   后续通过 App 适配器粘贴一个已存在、支持调光的 `light.xxx` 作为目标。
4. 等待保存后复位，确认相同 key 和目标仍有效。用触摸测试真实灯光开关与调光，
   再关闭 App 复测。
5. 显示同步须保持未完成，直到 HA Blueprint 或适配通过状态、仅亮度变化、
   目标 A→B、HA 重启、面板重连和目标不可用等测试。旧的固定目标示例不足以验收。

### 故障排查

| 问题 | 处理方法 |
| --- | --- |
| HA 连不上面板 | 检查局域网连通性与 TCP 6053；组播发现不可用时使用已验证的 IP |
| 触摸无效 | 检查目标是否存在、是否支持调光、集成连接和动作权限 |
| 显示仍跟随旧灯 | 动态状态推送尚待实现；更改控制目标不会自动实现显示同步 |
| 私有 key 记录丢失 | 停止并进入明确授权的恢复流程；普通复位不会清除已安装 key |

### 部署完成

此候选仅供内容审阅。烧录写入校验、加密 API 验证、HA 灯光与显示验收分别记录。
人工步骤的渲染器可能不执行任何设备操作就标记完成；适配和验收通过前须保持方案禁用。
