# E1003 灯光面板配置演示

连接设备，填写要控制的灯。App 会自动检查并按需安装固件。

这是一个技术演示：在同一表单配置灯光绑定，无需编译、编辑配置文件或填写 API 密钥。

## 可以测试什么

- 为 E1003 指定一盏 HA 调光灯。
- 查看配置保存、重启和读回结果。
- 保存成功后，接入 HA，再验证面板控灯。

仅灯开关和 25%、50%、75%、100% 亮度五个区域定义了触摸动作，其它图形没有点击绑定。实际触摸、HA 控灯与屏幕同步仍待验收。
