# E1003 统一部署技术演示

在桌面 App 的同一表单选择 E1003 并填写配置。App 自动核对设备固件，匹配就直接配置，否则按需安装统一预编译镜像，再保存网络、独立连接密钥与灯光按钮绑定。无需选择是否烧录、编译或编辑 `secrets.yaml`。

**已验证：** 打包后端与共享前端完成匹配后跳过烧录、保存 65 秒、复位及加密读回。受控安装测试也完成真实写入和校验：只将首次固件探测设为无响应，随后实机操作保持原密钥与绑定。该测试未覆盖出厂空白设备；新 Wi-Fi、真实 Home Assistant 控灯和屏幕状态同步仍待验收。

## 演示中得到什么

- 一份固定布局的预编译固件，包含时钟、温湿度和灯光卡片。
- 每台设备独立的连接密钥，以及复位后保留的灯光绑定；更换绑定无需重编译。
- App 内的保存进度、加密读回结果和密钥复制按钮。

灯光卡片的开关与四档亮度共用“按钮控制的灯”这一项设置。写入该项只证明绑定保存成功，实际控灯需在 Home Assistant 单独测试。

## 如何测试

1. 通过 USB 连接 E1003，在 App 同一表单选择串口并填写“按钮控制的灯”，如 `light.bedroom`。首次联网填写 Wi-Fi；同一 App 已有记录且设备已联网时可留空。
2. 点击 **部署并保存配置**。App 检查项目标识、版本和硬件；匹配时跳过烧录，不匹配时先校验镜像再安装。无需切换套餐或手动判断。
3. 保持通电，等待配置写入、65 秒保存、复位及加密读回通过。随后在 App 内复制密钥，到 Home Assistant 确认设备、允许执行动作，再单独测试控灯。

## 接口与条件

USB 使用 Improv Serial 配网；局域网使用加密 ESPHome 原生 API（TCP 6053）配置和读回。无需 MQTT 或设备网页服务。配置电脑、面板和 Home Assistant 须互通；控灯测试需要已有的可调光灯实体。

仅适用于 E1003 当前固定布局，通过 USB 更新，不支持 OTA。任意灯的状态与亮度显示同步仍需 HA Blueprint 或适配。
