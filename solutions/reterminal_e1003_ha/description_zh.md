# 把 Home Assistant 控制放到 E1003 面板上

固定界面包含时钟、温湿度和灯光卡片。灯光卡片的开关和四档亮度按钮共用一项设置：按钮控制的灯。

> 本地联调已提供安装和配置入口：从 App 打开设置表单，即可修改按钮控制的灯，无需手动命令。正式方案仍禁用；真实 HA 控灯、该表单的新网络配网和屏幕状态同步仍待验证。

## 需要设置什么

| 设置 | 用途 |
| --- | --- |
| Wi-Fi 名称和密码（可选） | 已联网时留空，沿用当前网络；首次联网或更换网络时填写 |
| 按钮控制的灯 | 从 Home Assistant 复制灯的实体 ID，如 `light.bedroom` |

设备连接密钥首次设置时自动生成，后续复用；可在配置表单勾选复制到本机，接入 Home Assistant 时粘贴。安装采用预编译程序，无需编辑配置文件或编译。

## 适用场景

- 放在床头，查看时间，使用灯光卡片开关灯或调节亮度。
- 放在办公桌旁，查看温湿度，操作工作区照明。

## 使用须知

- 使用 reTerminal E1003 和当前固定布局，准备一盏已接入 Home Assistant、支持调光的灯。
- 配置电脑、面板与 Home Assistant 需在同一可达局域网。
- 设备通过 ESPHome 原生 API 连接 Home Assistant，无需 MQTT 或设备网页服务。
- 当前通过 USB 安装和更新，不支持无线更新（OTA）。
