# E1003 统一部署技术演示

在桌面 App 同一表单选择设备并填写灯光设置，目标流程由 App 自动检查固件、按需安装 0.2.1，再保存配置。**参考固件仅使用免密明文 API，不提供加密选项**；设备已有可用 Wi-Fi 时可直接复用，无需事先保存本机密钥记录，也无需编译或编辑 `secrets.yaml`。

**当前状态：** 0.2.1 已构建，编译产物不包含 API 加密能力；App 的加密勾选和密钥复制入口已移除，依赖 contract 14。软件检查与共享前端截图审查通过，但 WCH 串口在上传前消失，0.2.1 尚未真机烧录。旧 0.2.0 的结果不代替本版实机验收。

## 演示中得到什么

- 同一份预编译固件，固定显示时钟、温湿度和灯光卡片。
- 仅支持免 API 密钥连接的参考固件；不生成、填写或复制 API key。
- 复位后保留的灯光绑定，以及 App 内的检查、安装和保存进度。

固件只为灯光开关与 25%、50%、75%、100% 亮度定义了五个触摸区，共用“按钮控制的灯”。其它图形没有点击绑定；这不表示触摸或真实控灯已验收；墨水屏断电保留图像，也不能证明触摸电路有电。

## 如何测试

1. 连接 USB，在 App 选择串口并填写“按钮控制的灯”，如 `light.bedroom`。已有网络时 Wi-Fi 留空；首次联网时填写名称和密码。
2. 最终资源和兼容 App 就绪后，点击 **部署并保存配置**，不选择加密或填写 key。App 按项目标识、版本和硬件检查固件，匹配则跳过，否则校验镜像后安装。
3. 保持供电直到 65 秒保存、复位和读回通过。在 Home Assistant 按免 API 密钥方式确认设备，不复制密钥。允许设备执行 HA 动作后，再单独验证五个触摸区。

## 接口与条件

使用 Improv Serial 与 ESPHome 原生 API（TCP 6053），无需 MQTT 或设备网页服务。0.2.1 参考设计只使用明文 API；电脑、设备与 HA 需在同一可达局域网。

仅支持 E1003 当前固定布局和 USB 更新，不支持 OTA。任意灯的状态与亮度同步仍需 HA Blueprint 或适配。
