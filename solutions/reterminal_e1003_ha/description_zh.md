# reTerminal E1003 智能家居控制面板

## 这个方案能帮你做什么

传统智能家居控制要么依赖手机 App 操作繁琐，要么使用发光液晶屏在夜间刺眼且功耗较高。本方案使用搭载低功耗电子墨水屏的 reTerminal E1003 作为家庭常显智能控制面板，通过 ESPHome 原生无缝接入 Home Assistant，无需云端中转即可实现本地触控开关灯光、阶梯调光以及联动全屋智能场景。

## 核心价值

| 核心优势 | 具体说明 |
|----------|----------|
| 柔和护眼常显 | 电子墨水屏静态无频闪、夜间无刺眼背光，宛如纸质标签般自然融入卧室和客厅环境 |
| 极低能耗长效 | 仅在画面刷新或操作时消耗电量，支持断电画面持久保留，可长期稳定通电运行 |
| 原生本地联动 | 基于 ESPHome Native API 与 Home Assistant 局域网直连，响应迅速且不依赖任何外部云端 |
| 开箱快速部署 | 一键烧录出厂固件并自动完成 HA 识别与设备注册，告别复杂的代码编译与底层配置 |

## 适用场景

| 场景 | 怎么用 |
|------|--------|
| 床头调光与开关 | 伸手轻触面板即可开关床头灯或平滑调节 25%、50%、75%、100% 亮度，夜间使用不晃眼 |
| 玄关离家与回家场景 | 出门前一键触发“全屋离家”（关闭照明、启动安防），回家轻触唤醒舒适照明与温控 |
| 客厅多路情景切换 | 一键切换观影、阅读或会客模式，直观掌控全屋智能联动与灯光氛围 |

## 使用须知

### 核心硬件设备

| 设备 | 说明 | 必需 |
|------|------|------|
| reTerminal E1003 | 触控电子墨水屏面板终端（ESP32-S3） | ✓ 必选 |
| USB 数据线 | 用于首次固件烧录与面板供电 | ✓ 必选 |
| Linux 主机 / 树莓派 | 用于运行 Home Assistant 服务（已有 HA 实例可自动复用） | ✓ 必选 |

### 网络要求

- 面板首次配网需连接 2.4 GHz Wi-Fi（不支持仅 5 GHz 频段）。
- 部署电脑、reTerminal E1003 面板与 Home Assistant 主机须处于同一局域网并可互相通信。
