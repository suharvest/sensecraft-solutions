# 用 E1003 控制 Home Assistant 灯光

这套方案适合已有 Home Assistant 的家庭或办公室，目标是在 reTerminal E1003 的固定触控界面上控制一盏可调光灯。

> 当前仍为候选版本，暂不支持在 App 内完成部署。USB 固件分发与设备配置入口仍在接入，任意灯光目标的状态与亮度同步也尚未完成。

## 这个方案能帮你做什么

完成配置后，面板应能开关目标灯并调节亮度。方案采用预编译固件，目标是让用户在 App 里直接完成设置，无需手动修改配置文件或自行编译。

| 配置内容 | 用途 |
| --- | --- |
| Wi-Fi | 让面板连入家庭或办公室的局域网 |
| 设备独立加密密钥 | 供 Home Assistant 安全连接面板 |
| 灯光实体 `light.xxx` | 指定要控制的目标灯 |

## 适用场景

- 在床头放置：睡前随手开关卧室灯或调暗亮度。
- 在办公桌旁放置：工作时快速调节工作区照明。

## 使用须知

- 仅适用于 reTerminal E1003 硬件及当前的固定屏幕布局。
- 需要已有运行中的 Home Assistant 环境，并接入至少一盏支持调光的灯。
- 配置电脑、E1003 面板与 Home Assistant 必须处于同一个可互通的局域网内。
- 设备通过 ESPHome 原生 API 直连 Home Assistant，不需要另外搭建 MQTT 或设备网页服务。
- 目前仅支持通过 USB 线更新，不支持无线 OTA。
- 更改灯光目标只会绑定控制动作，屏幕上的状态和亮度不会自动同步（需要后续配合 HA Blueprint 或适配支持）。
