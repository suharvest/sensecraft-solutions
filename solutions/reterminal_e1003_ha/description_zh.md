# 全屋智能交互屏幕

## 这个方案能帮你做什么

控制全屋智能，往往得先找手机开 App，或者忍受发光屏幕在暗光下的刺眼光线。这个方案把一块小巧的面板变成固定在墙上的 Home Assistant 控制屏，全部本地运行，不走云端。提供三个套餐可选：

- **墨水屏（reTerminal E1003）**：省电、不晃眼，经 ESPHome 原生 API 接入。
- **桌面彩屏（SenseCAP Indicator）**：一屏看更多环境状态、触控更丰富，经 ESPHome 原生 API 接入。
- **旗舰彩屏（reTerminal D1001）**：ESP32-P4 双核高性能驱动，800×1280 高清 MIPI-DSI 广视角大屏，支持横竖屏呈现，基于 PocketJS 现代 UI 引擎，内置出厂 HA 控制面板，滑动调光丝滑流畅。

## 核心价值

| 核心优势 | 具体说明 |
|----------|----------|
| 柔和护眼常显 | 电子墨水屏没有频闪，暗光下也没有刺眼背光，放卧室或客厅就像一张纸质便签 |
| 极低能耗长效 | 墨水屏只有屏幕刷新和操作时才耗电，断电画面也不消失，长时间通电用着省心 |
| 原生本地联动 | 通过 ESPHome 原生 API 或局域网直连调用 Home Assistant，面板点一下灯就响应，断网也能局域网本地跑 |
| 三种形态可选 | 卧室/床头选护眼墨水屏，紧凑桌面选 Indicator 方彩屏，客厅/入户等全屋核心位置选 D1001 旗舰高清大屏 |
| 旗舰高刷动效 | reTerminal D1001 具备硬件 2D/DMA 加速与双核 RISC-V 性能，配合 PocketJS 引擎，调光与滑动交互达到 60fps 丝滑水准 |
| 横竖摆放自由 | reTerminal D1001 硬件原生支持横屏与竖屏摆放，出厂应用已精细调校高密度全屋中控卡片与快捷操作 |
| 开箱快速部署 | 一键刷入出厂固件，自动接入 Home Assistant，不需要自己编译代码或手写底层驱动配置 |

## 适用场景

| 场景 | 怎么用 |
|------|--------|
| 床头调光与开关 | 睡前伸手点一下就能开关灯，或直接切换 25%、50%、75%、100% 亮度，夜里开灯不晃眼 |
| 玄关离家与回家场景 | 门口按一下就能触发“全屋离家”（关掉全部灯光、开启布防），进门轻触即可恢复常用灯光和空调 |
| 客厅旗舰全屋中控 | 在 reTerminal D1001 大屏上总览全屋状态，滑动精细调光、切换多路情景、查看实时天气预报 |

## 使用须知

### 核心硬件设备

| 设备 | 说明 | 必需 |
|------|------|------|
| reTerminal E1003 | 触控电子墨水屏面板终端（ESP32-S3），墨水屏套餐使用 | ✓ 三选一 |
| SenseCAP Indicator（D1 / D1S / D1Pro / D1L） | 彩屏触控面板（ESP32-S3），桌面彩屏套餐使用 | ✓ 三选一 |
| reTerminal D1001 | 800×1280 旗舰触控彩屏终端（ESP32-P4 + ESP32-C6），旗舰彩屏套餐使用 | ✓ 三选一 |
| USB 数据线 | 用于首次固件烧录与面板供电（D1001 建议使用 USB-C 高速数据线） | ✓ 必选 |
| Linux 主机 / 树莓派 | 用于运行 Home Assistant 服务（已有 HA 实例可直接复用；本地容器部署仅支持 Linux host 网络） | ✓ 必选 |

### 网络要求

- 面板首次配网需连接 2.4 GHz Wi-Fi（不支持仅 5 GHz 频段）。
- 部署电脑、面板与 Home Assistant 主机须处于同一局域网并可互相通信。
