# E1003 灯光面板配置演示

通过 USB 将 reTerminal E1003 连接到电脑，在 App 中指定要控制的 Home Assistant 调光灯。App 会检查设备并按需安装预编译固件，然后保存灯光绑定与网络配置。

整个过程在单一表单中完成，无需自行编译固件、改写配置文件或填写 API 密钥。

## 用途与准备

把 E1003 屏幕上的触控按键绑定到 Home Assistant 中的一盏调光灯（`light.*`）。

开始前，请准备好：

- 一台 reTerminal E1003 面板与一根 USB 数据线。
- 一台运行 App 的电脑，以及同局域网内已正常运行的 Home Assistant。
- 目标调光灯的实体 ID（例如 `light.bedroom`）。

## 怎么开始

1. 用 USB 数据线将 E1003 连接到电脑，在 App 中选择对应串口。
2. 填写目标灯实体 ID，需要配网时填入 2.4 GHz Wi-Fi（若设备已连过该网络可留空）。
3. 点击 **保存配置**。App 会自动检查固件、写入设置并重启验证。
4. 验证成功后，按界面提示在 Home Assistant 中添加该 ESPHome 设备并允许执行动作。

> **功能说明**：当前屏幕仅定义了开关与 25%、50%、75%、100% 亮度五个触摸区域，其余图标为静态展示；实际按键控灯与屏幕双向状态同步仍待后续适配与验收。
