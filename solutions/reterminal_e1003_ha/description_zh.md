# 全屋智能交互屏幕

## 这个方案能帮你做什么

控制全屋智能，往往得先找手机开 App，或者忍受发光屏幕在暗光下的刺眼光线。这个方案把一块小巧的面板变成固定在墙上的 Home Assistant 控制屏，全部本地运行，不走云端。提供两个套餐可选：

- **墨水屏（reTerminal E1003）**：省电、不晃眼，经 ESPHome 原生 API 接入。
- **彩屏（SenseCAP Indicator）**：一屏看更多状态、触控更丰富，经 ESPHome 原生 API 接入。

## 核心价值

| 核心优势 | 具体说明 |
|----------|----------|
| 柔和护眼常显 | 电子墨水屏没有频闪，暗光下也没有刺眼背光，放卧室或客厅就像一张纸质便签 |
| 极低能耗长效 | 只有屏幕刷新和操作时才耗电，就算断电画面也不会消失，长时间通电用着省心 |
| 原生本地联动 | 通过 ESPHome 原生 API 直接调用 Home Assistant，面板点一下灯就响应，不用写复杂联动，断网也能本地跑 |
| 两种屏幕可选 | 卧室、床头等需要柔和常显的地方选墨水屏，需要展示更多设备状态和频繁触控的地方选彩屏 |
| 开箱快速部署 | 一键刷入固件，自动接入 Home Assistant，不需要自己编译代码或手写 YAML 配置 |

## 适用场景

| 场景 | 怎么用 |
|------|--------|
| 床头调光与开关 | 睡前伸手点一下就能开关灯，或直接切换 25%、50%、75%、100% 亮度，夜里开灯不晃眼 |
| 玄关离家与回家场景 | 门口按一下就能触发“全屋离家”（关掉全部灯光、开启布防），进门轻触即可恢复常用灯光和空调 |
| 客厅多路情景切换 | 在面板上直接切换观影、阅读或待客模式，不用拿手机也能管好全屋灯光 |

## 使用须知

### 核心硬件设备

| 设备 | 说明 | 必需 |
|------|------|------|
| reTerminal E1003 | 触控电子墨水屏面板终端（ESP32-S3），墨水屏套餐使用 | ✓ 二选一 |
| SenseCAP Indicator（D1 / D1S / D1Pro / D1L） | 彩屏触控面板（ESP32-S3），彩屏套餐使用 | ✓ 二选一 |
| USB 数据线 | 用于首次固件烧录与面板供电 | ✓ 必选 |
| Linux 主机 / 树莓派 | 用于运行 Home Assistant 服务（已有 HA 实例可直接复用；本地容器部署仅支持 Linux host 网络） | ✓ 必选 |

### 网络要求

- 面板首次配网需连接 2.4 GHz Wi-Fi（不支持仅 5 GHz 频段）。
- 部署电脑、面板与 Home Assistant 主机须处于同一局域网并可互相通信。
