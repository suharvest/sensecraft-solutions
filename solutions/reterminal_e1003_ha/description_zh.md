# E1003 预编译固件与运行时配置演示

测试同一份固件如何用于不同 E1003：通过 USB 安装后，在桌面 App 内配置网络、设备独立连接密钥和灯光按钮绑定。无需编译、编辑 `secrets.yaml` 或运行维护者脚本。

**已验证：** App 烧录，以及原生 macOS 窗口通过内置表单写入测试灯的 ID、等待 65 秒保存、复位后加密读回；窗口复制密钥也已核对通过。新 Wi-Fi 表单配网、真实 Home Assistant 控灯和屏幕状态同步仍待实机验收。

## 演示中得到什么

- 一份固定布局的预编译固件，包含时钟、温湿度和灯光卡片。
- 每台设备独立的连接密钥，以及复位后保留的灯光绑定；更换绑定无需重编译。
- App 内的保存进度、加密读回结果和密钥复制按钮。

灯光卡片的开关与四档亮度共用“按钮控制的灯”这一项设置。写入该项只证明绑定保存成功，实际控灯需在 Home Assistant 单独测试。

## 如何测试

1. 首次使用时通过 USB 安装固件；已安装这份固件可直接配置。
2. 在 App 内置表单选择 USB 端口，填入灯的实体 ID（如 `light.bedroom`）。首次联网时填写 Wi-Fi；同一 App 已有该设备记录且设备已联网时可留空。
3. 点击保存，保持通电直到复位与加密读回通过。随后在 App 内复制密钥，到 Home Assistant 确认设备、允许执行动作，再测试面板按钮。

## 接口与条件

USB 使用 Improv Serial 配网；局域网使用加密 ESPHome 原生 API（TCP 6053）配置和读回。无需 MQTT 或设备网页服务。配置电脑、面板和 Home Assistant 须互通；控灯测试需要已有的可调光灯实体。

仅适用于 E1003 当前固定布局，通过 USB 更新，不支持 OTA。任意灯的状态与亮度显示同步仍需 HA Blueprint 或适配。
