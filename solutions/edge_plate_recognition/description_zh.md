## 这个方案能帮你做什么

出入口抬杆要么靠人盯，要么买整套车牌识别一体机、换掉现有摄像头。这个方案保留你已经装好的出入口摄像头，加一台识别主机在现场读车牌；白名单里的车到了，道闸自动抬杆，每次进出都留下车牌号和截图记录。车牌和画面都留在现场，不上云。

## 核心价值

| 好处 | 具体说明 |
|------|---------|
| 不换摄像头 | 直接接入现有 1080p 网络摄像头，识别主机通过局域网拉取画面 |
| 白名单车辆自动抬杆 | 车牌在白名单里就给道闸发一次开闸信号；关闸仍由道闸自己的地感或雷达负责 |
| 每辆车一条记录 | 一辆车只上报一次：车牌号、可信度和截图链接，停车场系统订阅一次就能收到所有出入口的数据 |
| 数据留在现场 | 截图存在识别主机上，默认保留 7 天；只有按链接取图时才传出 |
| 实测处理速度 | 在 Jetson Orin Nano 上处理 1080p 画面，每秒约 30 帧，单帧车牌检测约 6 毫秒 |

## 适用场景

| 场景 | 怎么用 |
|------|--------|
| 小区 / 园区出入口 | 业主车牌导入白名单，车到杆抬；访客车照常由岗亭放行 |
| 企业员工停车场 | 员工车牌按有效期导入，到期自动失效 |
| 停车场进出记录 | 不接道闸，只记录每辆车的车牌、时间和截图，供停车场系统对账 |

## 使用须知

### 核心硬件设备

| 设备 | 说明 | 必需 |
|------|------|------|
| reComputer J30 / J40（Jetson Orin Nano / Orin NX，JetPack 6.2） | 识别主机：拉取摄像头画面、识别车牌 | 三选一 |
| reComputer RK3588 系列 | 识别主机：拉取摄像头画面、识别车牌 | 三选一 |
| reComputer RK3576 系列 | 识别主机：拉取摄像头画面、识别车牌 | 三选一 |
| 网络摄像头 | 你已有的出入口摄像头，1080p 及以上，支持 RTSP 视频流 | ✓ 必选 |
| reComputer R1100 系列（R1124-10） | 道闸控制器：收发识别消息、比对白名单，用数字输出给道闸发开闸信号 | 需要自动抬杆时 |
| 中间继电器 | 导轨式，接在道闸控制器与道闸之间 | 需要自动抬杆时 |

- Jetson 支持 Orin Nano 和 Orin NX 模组（reComputer J30 / J40），需运行 JetPack 6.2。
- 摄像头装在距车道 3–8 米处，车牌在画面里清晰可读。

### 网络要求

- 摄像头、识别主机、道闸控制器在同一局域网，建议有线连接。
- 首次部署时识别主机需要联网，下载运行程序和识别模型；部署完成后可断网运行。

### 识别范围

- 支持中国大陆单行车牌：蓝牌（7 位）和新能源绿牌（8 位）。
- 不支持双行车牌、特种车牌和海外车牌。
- 实测准确率（公开数据集 CCPD 静态图，均未参与训练；视频多帧投票用每张静态图的 7 个视角模拟）：绿牌 1000 张，单张整牌读对 80.5%；投票后 89.0% 的车辆报出车牌，报出的车牌 91.7% 正确。蓝牌 2400 张（含夜间、模糊、倾斜、旋转、远距离），单张整牌读对 81.1%。Jetson Orin Nano、RK3588、RK3576 之间相差不超过 2 个百分点（504 张子集）。
- 上线前用你自己出入口的白天和夜间画面，对照实际车牌检查识别结果。
