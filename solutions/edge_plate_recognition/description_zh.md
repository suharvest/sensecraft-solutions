# 边缘车牌识别

> **草稿（staging）。** 本参考设计尚未通过真机验收。本页不发布任何识别率、
> 时延或帧率数字——发布前会按平台用验收实测结果回填。

在摄像头所在的边缘侧识别车牌，而不是在云端。车辆到达出入口；车牌被检测、
逐字符识别，并跨多帧投票；每辆车只发一条 MQTT 事件，附截图链接。车牌在
白名单内时，道闸收到一个开闸脉冲——同时另一条事件记录是谁触发的、脉冲
花了多长时间。

## 边缘主机上的同一套管线

- **主机端**：保留现有出入口 IP 摄像头。一台 reComputer（Jetson Orin、
  RK3588、RK3576 或 Hailo-8）拉 RTSP 流跑模型——一台主机可覆盖多条车道。
- **摄像头端**（reCamera Pro / reCamera 2002 HQ PoE）：本版本不提供，机上应用尚未发布。

各主机发布同一套事件契约，车场系统只需订阅一次，与出入口用什么硬件
无关。

## 失效安全的开闸

所有开闸都经过一台 reComputer R1124-10：它运行 MQTT broker 和开闸服务，
把车牌与本地白名单匹配（CSV 经 HTTP 上传，归一化后精确匹配——不做模糊
匹配），命中时用数字输出经中间继电器给道闸「开闸」输入一个脉冲。脉冲带
冷却保护，补发的历史事件和过期事件不会开闸，任何异常时输出强制复位为
常开。关闸始终是道闸控制器自己的职责。

## 天生的隐私设计

事件只带车牌字符串、置信度和截图*引用*——图片不随事件传输。截图留在设备
本地，默认保留 7 天并有容量上限，只有你按链接取图时才经 HTTP 传出。没有
云端车牌库，也没有视频上行；要不要接云端是你自己的集成选择，不是默认
行为。

首发支持的车牌制式：中国大陆单行牌（蓝牌 7 位、新能源绿牌 8 位）。双行
牌、特种牌与海外制式不在本期范围。
