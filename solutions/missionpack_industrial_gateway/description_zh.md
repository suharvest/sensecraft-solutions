## 这个方案能帮你做什么

做楼宇、能源或设备管理方案时，最费时间的往往不是看板，而是每到一个现场都要重新适配控制器、点位地址和数据格式。这个方案把 OPC UA、Modbus、BACnet/IP 和 MQTT 接进同一套点位模型，上层系统只需对接一套 MQTT 读写接口。

现场差异通过配置解决：添加控制器、自动发现或手动填写点位、确认数据质量，再把选定数据提供给能耗平台、SCADA、云平台或客户应用。方案商不必在每个项目里重复维护协议驱动和字段转换逻辑。

方案优先面向 reComputer R1000/R1100 系列和 reTerminal DM 系列，其中 reTerminal DM 可直接通过本机触控屏完成日常配置与操作。

预测流程作为可选插件保留。多协议接入、统一点位管理和数据服务可以独立使用，不需要训练模型。

## 核心价值

| 好处 | 现场如何使用 |
|------|--------------|
| 一次对接多种现场协议 | OPC UA、Modbus TCP/RTU、BACnet/IP 和 MQTT 都进入同一套点位模型，上层应用无需分别适配 |
| 把现场差异变成配置 | 浏览 OPC UA 节点、扫描 Modbus 站号、执行 BACnet Who-Is 或观察 MQTT 主题；自动发现不完整时可直接手动填写 |
| 一套接口读写全部点位 | 内置 Broker 提供带版本的数据、在线状态、命令和回执主题，方案商只维护一套北向接口 |
| 控制结果可确认、可追溯 | 写入前确认权限与数据质量，写入后查看生效值、设备读回和命令回执，降低误控风险 |
| 接入能力可跨项目复用 | 新项目主要调整控制器和点位配置，不必重新开发看板到设备之间的协议转换层 |

## 适用场景

| 场景 | 怎么用 |
|------|--------|
| 楼宇能耗方案交付 | 把 BACnet/IP 空调机组和 Modbus 电表汇入统一点位模型，再将数据送到能耗看板或客户平台 |
| 暖通系统改造 | 保留现有 OPC UA 控制器，同时加入 MQTT 传感器，上层控制逻辑继续使用同一套接口 |
| 多品牌设备集成 | 在 reComputer R1000/R1100 或 reTerminal DM 上消化不同厂商的协议和地址差异，对客户系统统一输出 |
| 受控节能优化 | 在统一点位之上启用预测插件，导入 CSV、选择输入输出参数，并追踪每次控制结果 |

这些运行暴露的未决问题：

- 预测循环是"跑完一个 cycle 再固定 sleep"，因此速率是 `1/(1.0 + t_cycle)`。2,000 点规模下 `t_cycle` 约 0.119 s，结构上限落在 0.894 cycle/s 附近，低于 0.90 的门禁阈值。第三轮四次运行全部复现，包括不注入断网的对照跑。要么改循环要么改门槛，目前未修。
- 全部北向实测都跑在单机回环的明文链路上，运行档为 test。生产的严格 TLS 路径与真实弱网（抖动、部分丢包、半开连接）均未覆盖。
- 这里的"断网"是杀掉 broker 进程或容器，不是链路劣化。

## 使用须知

### 核心硬件设备

| 设备 | 说明 | 必需 |
|------|------|------|
| reComputer R1000 系列 | 运行多协议接入、统一点位模型、MQTT 数据服务和管理界面 | 三选一 |
| reComputer R1100 系列 | 运行多协议接入、统一点位模型、MQTT 数据服务和管理界面 | 三选一 |
| reTerminal DM 系列 | 运行相同服务，并通过本机触控屏完成配置与日常操作 | 三选一 |
| USB 转 RS-485 适配器 | 连接 Modbus RTU 总线 | 仅 Modbus RTU 需要 |

### 网络与协议边界

- 运行数据中枢的设备必须能够访问各以太网协议所在网络。BACnet 广播发现可能需要选择正确网卡，并保证设备位于可达网段。
- OPC UA 浏览、BACnet Who-Is、Modbus TCP 站号扫描和 MQTT 主题观察只生成候选项；用户确认后才会进入正式点位表。
- 已包含 Modbus RTU 配置和通讯能力，但标准 Docker 配置不会挂载主机串口。需要使用串口设备安装方式；在指定 USB 转 RS-485 适配器与目标控制器通过真实硬件联调前，生产写控制必须保持关闭。
- 远程 Linux 部署使用主机网络，以便 BACnet/IP 广播发现进入物理网段；Docker Desktop 的本机桥接部署可能需要手动填写 BACnet 地址。
- 部署时会先运行一个无网络的一次性卷权限迁移任务，再启动非 root 数据服务。它会保留旧 root 镜像生成的数据，同时让长期运行进程保持无特权身份。
- 北向数据服务使用原生 **MissionPack v1 MQTT 主题契约**。它借鉴工业设备生命周期消息，但当前版本**不宣称兼容 Sparkplug B**。
- 明文 MQTT 只允许遥测数据。需要远程控制时，必须启用 TLS 并配置具有控制权限的身份。
