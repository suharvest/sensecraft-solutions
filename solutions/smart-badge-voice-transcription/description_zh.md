## 这个方案能帮你做什么

reSpeaker Clip 的录音在你自己的主机上转成文字并分清说话人，录音不上云。

佩戴 reSpeaker Clip 完成现场录音，回到主机附近后通过蓝牙（BLE）或 Wi-Fi 自动同步音频文件。边缘算力主机在本地完成语音活动检测（VAD）、说话人分离（Diarization）和语音识别（ASR），生成带有精确时间戳和发言人标签的结构化文字稿，并通过本地 Web 页面和 MQTT/HTTP API 实时提供。

- **录音自动同步**：佩戴 Clip 录音，靠近主机后经 BLE 自动回传音频，无需手动插线拔卡。
- **本地转写与说话人分离**：在本地边缘主机上完成说话人区分与 ASR，分清每位说话人的发言回合。
- **带时间戳文本输出**：转写结果按说话人分段并标注起止时间，支持在网页端点选句子从对应时间戳开始回放。

## 核心价值

- **录音全流程不上云**：原始录音在本地处理和保存，敏感会议、商务谈判或诊疗对话不经过任何外部公有云，保障隐私安全。
- **双平台硬件加速**：支持 reComputer J40 系列（Jetson Orin NX，GPU TensorRT 加速）与 reComputer RK3576 系列（NPU RKNN 加速）。
- **开箱即用的管理页面**：提供录音列表与转写详情查看页面，支持按时间与设备筛选，也可直接上传 WAV 文件手动转写。
- **可选 AI 智能摘要**：支持配置 OpenAI 兼容端点（如本地部署的 LLM 服务或自有 API），自动提炼会议重点与行动项。

## 适用场景

录音要转成文字、但录音不能离开现场的业务场景：

- **门店与柜台服务**：店员佩戴 Clip，回到主机附近后录音自动同步，店长在管理页查看当天沟通记录与服务规范。
- **访谈与会议记录**：采访或商务会议结束后将 Clip 放在主机旁，同步完成后自动得到分好说话人的文字稿。
- **诊室、法务与内部咨询**：对隐私与数据合规要求严格的场合，录音全程不出场地，转写全部在自有主机上闭环。

## 实测效果

录音以 WAV 文件上传到主机，从上传到转写完成计时（测试音频来自公开数据集）：

| 指标 | 典型值 | 设备 |
|---|---|---|
| 26 秒双人中文录音 | **1.2 秒**转完，识别出 2 位说话人 | reComputer J40 系列（Orin NX 16GB） |
| 34 秒日语录音 | **1.7 秒**转完 | reComputer J40 系列（Orin NX 16GB） |
| 30 秒双人中文录音 | **4.6 秒**转完，识别出 2 位说话人 | reComputer RK3576 系列（8 GB） |

## 使用须知

- **单主机绑定**：一个 Clip 只能绑定一台主机，不能同时与手机 App 配对。
- **AI 摘要配置**：开启 AI 摘要时若配置云端端点，仅转写后的文字内容会发给该端点，录音音频本身始终不出主机；也可配置局域网内的私有 LLM 服务实现全离线。
- **硬件平台规格**：Jetson 预编译 TensorRT 语音镜像适配 Jetson Orin NX（JetPack 6.2，TensorRT 10.3）；RK3576 使用对应的 RKNN 运行时与模型。
