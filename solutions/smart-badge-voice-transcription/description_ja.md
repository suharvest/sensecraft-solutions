## このソリューションでできること

会議、相談、窓口対応など reSpeaker Clip で録音した会話は、通常はスマートフォンアプリとクラウドを経由して文字起こしされます。このソリューションは録音をお客様の reComputer (Jetson Orin NX または RK3576) へ直接同期し、そこで文字起こしします。録音は現場に残り、文字起こし結果はローカルの Web ページで閲覧するか、お客様のシステムに取り込めます。

## 主なメリット

| メリット | 内容 |
|---------|------|
| 録音は現場に保存 | Clip は Bluetooth でホストに同期し、文字起こしはホスト上で実行。クラウドには何もアップロードしません |
| 誰が何を話したか | 各区間にタイムスタンプと話者ラベルが付きます。中国語、英語、日本語を認識します |
| 高速 | Jetson Orin NX では 26 秒・話者 2 人の中国語録音を 1.2 秒で文字起こしし、話者 2 人を分離。RK3576 (8 GB) では 30 秒・話者 2 人の中国語録音を 4.6 秒で処理し、話者 2 人を分離 |
| システム連携 | 文字起こしが完了するたびに MQTT メッセージで通知し、お客様のプログラムが HTTP で全文を取得します |

## 利用シーン

| シーン | 使い方 |
|--------|--------|
| 店舗・窓口対応 | スタッフが Clip を身に着け、ホストの近くに戻ると録音が同期されます。管理者は結果ページでその日の会話を確認します |
| インタビュー・会議 | インタビュー後に Clip をホストの近くに置きます。同期が終わると、話者ごとに分かれた文字起こしができあがります |
| プライバシーに配慮が必要な現場 | 録音を施設外に出せないクリニック、法務、社内会議 |
| 業務システム連携 | 完了した文字起こしを、お客様のシステムがチケットや顧客記録に自動で取り込みます |

## ご利用にあたって

### 主要ハードウェア

| デバイス | 説明 | 必須 |
|---------|------|------|
| reSpeaker Clip | 装着型レコーダー | ✓ 必須 |
| reComputer J40 (Jetson Orin NX、JetPack 6.2) または reComputer RK3576 (8 GB) | 録音の同期、文字起こし、結果ページの提供 | ✓ 必須、2 つから 1 つ |
| Jetson 用ワイヤレスモジュール (Wi-Fi + Bluetooth) | ホストは Bluetooth で Clip に接続します。reComputer J40 と合わせて選んでください。RK3576 ホストにも Bluetooth が必要です | ✓ J40 の場合は必須 |

- Jetson は Jetson Orin NX モジュール、JetPack 6.2 のみ対応します。その他の Jetson モジュールや JetPack バージョンにはデプロイできません。
- RK3576 は 8 GB 版を選んでください。文字起こしには約 1.6 GB の空きメモリが必要なため、ボード上の他のサービスはその分を空けておく必要があります。
- 空きディスク：Jetson は 15 GB 以上、RK3576 は 5 GB 以上。
- Clip はこのホストにのみバインドでき、スマートフォンアプリと同時には使えません。

### ネットワーク要件

- 初回デプロイ時に音声モデル (Jetson は約 1.8 GB、RK3576 は約 460 MB) とランタイムをダウンロードするためインターネット接続が必要です。以降はオフラインで文字起こしできます。
- Clip は既定で Bluetooth で同期するため、ホストの Bluetooth 通信範囲内にある必要があります。
- 任意：高速 Wi-Fi 同期を有効にすると、ホストが Clip 自身のホットスポットに接続して録音をダウンロードします。ホストが有線 LAN でネットワークに接続している場合は内蔵 Wi-Fi を使い、ホストが Wi-Fi でネットワークに接続している場合は USB Wi-Fi アダプターを追加してください。
- 任意：AI 要約には OpenAI API 形式に対応した AI チャットサービスが必要です。クラウドサービスを使う場合は文字起こしテキストがそのサービスに送られます (録音は送られません)。お客様のネットワーク内のサービスを使う場合、すべてのデータは現場に残ります。
