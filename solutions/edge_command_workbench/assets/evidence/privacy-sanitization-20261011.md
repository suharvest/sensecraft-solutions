# Public evidence address sanitization / 公开证据地址脱敏

The public copies of the gallery and review metadata replace private Fleet IPv4 literals with RFC 5737 documentation addresses. Ports, request fields, model/image SHA-256 values, timings, and accuracy fields remain unchanged. The original private files and their machine-generated SHA-256 manifest are retained outside this repository for authorized review.

公开 gallery 和 review metadata 中的 Fleet 私有 IPv4 字面量已替换为 RFC 5737 文档地址。端口、请求字段、模型/镜像 SHA-256、耗时和准确率字段保持不变。原始私有文件及机器生成的 SHA-256 manifest 保存在仓库外，仅供授权审查使用。
