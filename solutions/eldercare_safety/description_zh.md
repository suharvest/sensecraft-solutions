# 居家养老安全守护 (Eldercare Safety Monitor)

面向居家长者意外防护与看护机构的端侧多模态智能守护系统，运行于搭载瑞芯微 RV1126B（3.0 TOPS NPU）的 **reCamera Pro** 边缘 AI 智能摄像头。

本系统深度整合计算机视觉姿态识别与端侧离线语音识别（ASR），单机一体化完成**骨架级跌倒检测**与**离线紧急呼救词识别**。所有计算在设备端本地闭环，**音视频流不出本地内存**，兼顾高时效性与长者个人隐私安全。

---

## 这个方案能帮你做什么

- **传统红外与毫米波雷达**：易受环境热源、宠物、扫地机器人干扰，难以区分坐在地上、低头捡东西与真正跌倒。
- **普通云端摄像头**：需持续上传视频流，长者在卧室、起居室等私密场景接受度极低，且面临断网即失效的风险。
- **多模态端侧协同**：
  - **视觉端**：高精度检测人体 17 个骨骼关节点，通过躯干倾角、质心垂直下降加速度及卧地时间窗判定跌倒；
  - **听觉端**：麦克风阵列配合端侧 VAD 与离线 ASR 模型，实时捕捉“救命”、“摔倒了”、“快来人”等求救词；
  - **决策融合**：视觉检测到跌倒且听到求救词时，告警置信度最高并即刻触发声光与远程联动；若视线被家具遮挡，仅凭声音求救亦可独立告警。

---

## 核心价值与技术规格

### 1. 骨架姿态与跌倒检测 (YOLO11n-Pose)
- **模型架构**：YOLO11n-Pose（RKNN INT8 量化），输出 17 个 COCO 骨骼关键点（头、肩、肘、腕、髋、膝、踝）。
- **跌倒状态机**：
  - **立姿 / 正常活动**（`upright`）：脊柱倾角与竖直方向夹角 < 45°；
  - **骤降事件**（`fall_event`）：质心竖直下降速度超过动力学阈值，躯干倾角骤增至 > 65°；
  - **确认跌倒**（`fallen`）：卧地保持不动持续时间超过 **3 秒**，触发不可逆跌倒告警；若在 3 秒内恢复站立，判定为轻度绊倒并平滑恢复，避免误报警。
- **推理表现**：RV1126B NPU 单帧推理延时约 **50 ms**，端到端吞吐率保持在 **15-20 FPS**。

### 2. 连续离线语音转写 (SenseVoice ASR)
- **声学前端**：Silero VAD（ONNX）实时语音活动检测，静音状态零 NPU 占用。
- **ASR 后端**：SenseVoice-Small T172 混合精度单模型（RKNN 量化），窗口 172 帧、重叠 32 帧。
- **识别准确率与延时**：
  - **中文 CER**：短语音 **1.8%** / 长语音 **2.5%**；
  - **英文 WER**：短语音 **3.9%** / 长语音 **2.8%**；
  - **实时率 (RTF)**：**≤ 0.11**（解码耗时仅为音频时长的十分之一）；
  - **求助词覆盖**：“救命”、“摔倒了”、“帮帮我”、“快来人”、“有人吗”、“Help”、“Emergency”。
- **完全离线**：不依赖公网外呼或云端 STT API，在断网环境下保持稳定守护。

### 3. 系统资源开销 (双模型并发实测)
- **CPU 占用**：四核 ARM Cortex-A7 均值约 **45%**；
- **内存安全下限**：可用内存始终保持 **> 500 MiB**；
- **整机运行功耗**：典型运行功耗约为 **3.5 W**。

## 输出接口

### 1. 结构化 MQTT 告警事件
设备支持将判定结果直接推送到局域网 MQTT Broker（如 Home Assistant、Node-RED 或看护工作站）。

- **主题模式**：`<device_name>/eldercare-monitor/events`
- **JSON 报文格式**：
```json
{
  "timestamp": 1729676400.450,
  "device_id": "living_room_cam",
  "fall_alert": {
    "detected": true,
    "state": "fallen",
    "person_id": 1,
    "confidence": 0.94,
    "torso_angle": 78.5,
    "immobility_sec": 3.2
  },
  "voice_alert": {
    "detected": true,
    "text": "救命啊摔倒了",
    "keyword": "救命",
    "confidence": 0.98,
    "duration_sec": 1.2
  }
}
```

### 2. 本地 WebSocket 实时预览流
- **端口与路径**：`ws://<device-ip>:8123/ws/inference/results`
- **功能**：输出包含骨架 17 点坐标、检测边界框与跟踪状态的二进制流，供 Web 端渲染实时热力或骨架图。

## 适用场景

- **居家长者起居看护**：卧室、客厅等私密生活空间，完全不外传音视频流，保障长者隐私。
- **养老机构与康养社区**：走廊、活动室等公共盲区，发生跌倒或呼救时毫秒级推送结构化告警。
- **孤寡与独居老人守护**：配合局域网 Home Assistant 或短信/电话联动网关实现闭环救援响应。

## 实测效果与使用须知

1. **安装高度**：建议安装在距地面 **2.2 - 2.5 米** 墙角或高处。
2. **俯拍倾角**：向下倾斜 **15° - 25°**，避免 90° 垂直俯拍（俯拍下关键点重叠严重导致姿态算法失效）。
3. **覆盖范围**：单台设备推荐覆盖长宽为 **4 米 × 5 米** 的房间（如长者卧室或客厅）。
4. **麦克风收音**：建议在 3-5 米半球半径内无大功率噪音源（如大风量风扇正对麦克风吹风）。
