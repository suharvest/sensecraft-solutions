# reCamera 选区运动检测

指定摄像头画面中哪些特定区域触发运动告警。reCamera 在本机 CPU 上利用传统计算机视觉算法完成检测，支持在控制台画面上自由划定多边形选区，提供 H.264 RTSP 视频流，并通过 MQTT 原生联动 Home Assistant。不需要深度学习 NPU 模型或云端服务。

适合监测门口、收银台、特定过道等多边形区域，同时避开树木晃动、道路车辆等容易造成干扰的干扰画面。

## 功能特性

- **画面直接绘制选区:** 在 reCamera 控制台视频画面上直接使用鼠标划定多边形运动检测区域（ROI）。
- **实时调试串流与叠加:** 8001 端口 WebSocket 实时输出 H.264 视频流，并在画面上叠加选区多边形、运动轮廓包围盒与告警状态卡片。
- **Home Assistant 原生联动:** 基于 MQTT Auto-Discovery 自动发现机制，HA 免安装任何第三方插件，自动生成运动传感器实体（`binary_sensor.recamera_motion`）。
- **标准 H.264 RTSP 串流:** 8554 端口输出 `/live0` 视频流，方便接入 NVR、VLC 及各类监控系统。
- **实时快照接口:** 8001 端口提供 `/snapshot.jpg` 高清 JPEG 抓拍。
- **低功耗 CPU 运行:** 不占用 NPU 资源，无需模型加载，响应迅速且功耗更低。
