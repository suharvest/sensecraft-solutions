# reCamera 选区运动检测

你可以指定摄像头画面中哪些区域触发运动告警。reCamera 在本机完成检测、保留近期事件抓拍，并提供 HTTP API、H.264 RTSP 视频流和 Webhook 通知。不需要云服务或 NPU 模型。

适合监测门口、工作台等多边形区域，同时忽略树木、道路等容易造成干扰的画面部分。Home Assistant 集成可以编辑检测区域、查看实时画面和事件抓拍。

## 功能

- 使用归一化坐标配置包含区域和排除区域
- 运动开始/结束事件，包含边界框和可选 JPEG 抓拍
- 8080 端口提供状态、配置、事件和抓拍 HTTP 接口
- 8554 端口提供 `/live0` H.264 RTSP 视频流
- 可选向 Home Assistant 或其他 HTTP 接收端发送 Webhook

摄像头视频管线由单个应用独占。服务启动时会停止系统自带的摄像头服务；切换到其他摄像头应用时，请使用 Solution 应用管理器。
