## このソリューションでできること

駐車場の空き台数を把握するには、通常は各レーンにループコイルを埋設するか、ゲートにカウンターを取り付ける必要があります。このソリューションは入口にある既存の IP カメラを使います。デプロイ後に Web ページで映像上にカウントラインを引くと、ラインを横切る車両を入庫・出庫として数え、場内台数と空き台数が変わるたびにお客様のシステムへ送ります。

## 主なメリット

| メリット | 内容 |
|---------|------|
| 既存カメラを使用 | 入口にある RTSP 対応 IP カメラに接続。ループコイルの埋設もゲートの改造も不要です |
| 入庫と出庫を別々に集計 | 通過ごとに入庫か出庫かを判定するため、双方向レーンでも正しく数えます |
| 空き台数をリアルタイム更新 | 通過のたびに場内台数と空き台数を送信。空き表示板や駐車場システムでそのまま使えます |
| 現場で処理 | 映像は入口近くのデバイスで解析し、外部に出るのはカウント値だけです |
| 車種判別 | 乗用車、二輪車、バス、トラックを区別し、通過記録ごとに車種が付きます |

## 利用シーン

| シーン | 使い方 |
|--------|--------|
| 商業施設・オフィスの駐車場 | 入口の表示板に「空き 37 台」と表示し、車両の出入りに合わせて更新します |
| キャンパス・工場のゲート | 1 日の入出庫合計を、トラックと乗用車に分けて集計します |
| 満車通知 | 空き台数が 0 になると駐車場システムがメッセージを受け取り、「満車」表示に切り替えます |
| 複数の入口 | 入口ごとに 1 セットを設置し、お客様のシステムでサイト ID ごとに合算します |

## デプロイ後に得られるもの

車両がカウントラインを横切るたびに、デバイスはお客様の MQTT サーバーへ 2 つのメッセージを送ります：

- **通過記録** (トピック `<サイト ID>/parking/<入口 ID>/crossing`)：方向 (入庫 / 出庫)、車種、信頼度、通過後の場内台数と空き台数。
- **駐車場の状態** (トピック `<サイト ID>/parking/<入口 ID>/occupancy`)：場内台数、総台数、空き台数、当日の入庫・出庫合計。

駐車場管理システム、空き表示板、Home Assistant はこの 2 つのトピックを購読してデータを利用します。

## ご利用にあたって

### 主要ハードウェア

| デバイス | 用途 | 必須 |
|---------|------|------|
| reComputer J30 / J40 (Jetson Orin Nano / Orin NX、JetPack 6.2) | カメラ映像を解析して台数を数えます。JetPack 6.2 が必要です | いずれか 1 つ |
| reComputer RK3588 シリーズ | カメラ映像を解析して台数を数えます | いずれか 1 つ |
| reComputer RK3576 シリーズ | カメラ映像を解析して台数を数えます | いずれか 1 つ |
| 入口の IP カメラ | RTSP ストリーム (H.264 または H.265)、レーンを固定画角で撮影 | ✓ 必須 |
| MQTT サーバー | カウント値を受け取ります。現場の既存サーバー、または Mosquitto を導入 | ✓ 必須 |

### ネットワーク要件

- カウント用デバイス、カメラ、MQTT サーバーが同じ LAN にあるか、相互に通信できる必要があります
- 初回デプロイ時にアプリ (約 0.5〜0.7 GB) と車両検出モデルをダウンロードします。以降はインターネットなしで動作します
- 1 台のデバイスで 1 台のカメラ、つまり 1 つの入口を担当します

## デプロイ方式の比較

| | reComputer J30 / J40 (Jetson Orin Nano / Orin NX) | reComputer RK3588 シリーズ | reComputer RK3576 シリーズ |
|---|---|---|---|
| 実測処理速度 | Orin Nano：30 フレーム/秒 (640×360 入力、30 fps) | 約 3 フレーム/秒 (1280×720 入力、5 fps) | 30 フレーム/秒 (640×360 入力、30 fps) |
| 1 フレームあたりの解析時間 | Orin Nano：約 3.6 ms | 約 18 ms | — |
| 適した現場 | 車両が通常速度で通過する入口 | 車両がゲートで減速・停止する入口 | 車両が通常速度で通過する入口 |
| システム要件 | Jetson Orin Nano または Orin NX モジュール、JetPack 6.2 | デプロイ手順でボードの NPU ランタイムと映像デコードライブラリを確認し、不足があればインストールすべきものを表示します | RK3588 と同じ |

Jetson Orin Nano での実測：30 fps のテスト映像で、41 回のライン通過すべてを正しい方向で集計しました。RK3588 の処理速度は約 3 フレーム/秒のため、確実に数えるには車両がラインを横切る際に約 1 秒以上映っている必要があります。RK3576 での実測：30 fps のテスト映像で全フレームを処理し、両方向の車両を集計しました。
