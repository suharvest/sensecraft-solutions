## 这个方案能帮你做什么

用现有出入口摄像头识别车牌，白名单车辆到了自动抬杆。

用现有出入口摄像头加一台现场主机读车牌，白名单车辆自动抬杆，每辆车留车牌和截图记录。面向停车场运营与系统集成商，跨平台部署。

- **实时车牌检测与识别**：出入口固定机位摄像头提供 RTSP 视频流，边缘主机自动框选车牌并准确识别号码。
- **白名单匹配与自动抬杆**：支持本地导入白名单 CSV，比对命中后通过继电器向道闸发送开闸脉冲信号。
- **车辆通行记录留存**：每辆车输出一条结构化 MQTT 记录（含车牌字符串、置信度、时间戳），并附带现场抓拍 JPEG 截图。

## 核心价值

- **利旧现有设备**：无需更换一体化车牌机，直接接入现有出入口 RTSP 摄像头，加装一台边缘主机即可完成智能化改造。
- **全流程本地闭环**：车牌识别、白名单判断与开闸逻辑全部在现场完成，断网不影响正常通行，车辆照片与行踪不出园区。
- **失效安全的电气设计**：开闸脉冲经中间继电器隔离输出，具备冷却保护时间，防止误发或连续打脉冲；关闸始终由道闸地感自带控制。
- **跨平台多算力支持**：支持 reComputer J30 / J40 系列（Jetson Orin Nano / NX）与 reComputer RK3588 / RK3576 系列。

## 适用场景

车辆在固定车道上通过、车牌在画面里清晰可辨的出入口：

- **小区与园区出入口**：业主或内部车辆导入白名单，车到杆自动抬起；访客车辆照常由岗亭人工放行。
- **企业员工停车场**：员工车牌按有效期批量导入，到期自动失效，通行记录可追溯。
- **只做进出记录的点位**：不联动道闸，仅记录每辆车的车牌、通行时间与抓拍照片，供停车场系统对账。

## 实测效果

输入为 1080p RTSP 视频流（基于 CCPD 车牌数据集）：

## 使用须知

- **支持车牌制式**：支持中国大陆 7 位民用蓝牌与 8 位新能源绿牌；双行黄牌、特种牌照及境外车牌暂不在支持范围。
- **机位安装规范**：摄像头距离车道约 3–8 米，固定角度俯视车牌，保证车牌在画面中清晰无严重畸变。
- **接口规范**：车牌事件发布至 MQTT `<site>/parking/<camera>/plate`，开闸动作发布至 `<site>/parking/<camera>/gate`，白名单通过 HTTP `/whitelist` 管理。
